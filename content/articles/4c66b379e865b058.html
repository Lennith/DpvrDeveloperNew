Video Playback Control¶

Video Rendering Format Types¶

public static class VideoRenderType
{
    public static int NORMAL_2D = 0;
    public static int NORMAL_3D_LEFT_RIGHT = 1;
    public static int NORMAL_3D_UP_DOWN = 2;
    public static int VR_180_2D = 3;
    public static int VR_180_3D_LEFT_RIGHT = 4;
    public static int VR_180_3D_UP_DOWN = 5;
    public static int VR_360_2D = 6;
    public static int VR_360_3D_LEFT_RIGHT = 7;
    public static int VR_360_3D_UP_DOWN = 8;
}

NORMAL_2D: Standard 2D video.

NORMAL_3D_LEFT_RIGHT: Left-right 3D video.

NORMAL_3D_UP_DOWN: Top-bottom 3D video.

VR_180_2D: 180-degree VR video.

VR_180_3D_LEFT_RIGHT: Left-right 180-degree VR video.

VR_180_3D_UP_DOWN: Top-bottom 180-degree VR video.

VR_360_2D: 360-degree VR video.

VR_360_3D_LEFT_RIGHT: Left-right 360-degree 3D VR video.

VR_360_3D_UP_DOWN: Top-bottom 360-degree 3D VR video.

Start Playback¶

public void VideoStart(string filePath, int mode = -1, bool startWhenPrepared = false, List<Client> clientList = null)

string filePath: File path of the video.

int mode: Rendering format, corresponding to the types listed above. Defaults to automatic selection.

bool startWhenPrepared: Automatically start playback after loading completes. Defaults to false; use VideoResume to resume playback if needed.

List<Client> clientList: List of clients for which to start playback. Default is null, indicating all clients.

Stop Playback¶

public void VideoStop(List<Client> clientList = null)

List<Client> clientList: List of clients for which to stop playback. Default is null, indicating all clients.

Note

The client selects the stop route used by the most recent 1002 playback message: it sends the stop command to com.dpvr.videoplayer.VIDEOPLAYERCONTROLLER when the DPVR player is used, or sends controltype=playcommand and operation=stop through com.deepoon.dpnlauncher.PLAY_CONTROL when playback falls back to DpnLauncher. This interface does not affect the RDC connection; whether the player UI exits is decided by the player app itself.

Pause Playback¶

public void VideoPause(List<Client> clientList = null)

List<Client> clientList: List of clients for which to pause playback. Default is null, indicating all clients.

Resume Playback¶

public void VideoResume(int delay = 0, List<Client> clientList = null)

int delay: Delay in seconds before resuming playback. Defaults to 0. The server adds this value to its current time and sends the resulting unified resume moment (PlayTime, format yyyy-MM-dd-HH-mm-ss) to the devices; all devices resume playback at that moment. A device that receives the command after that moment plays immediately. When using scheduled resume, make sure the device system time is synchronized with the server; multi-device sync precision is about ±1 second.

List<Client> clientList: List of clients for which to resume playback. Default is null, indicating all clients.

Seek Playback¶

public void VideoSeek(int time, List<Client> clientList = null)

int time: Time position to seek to, in seconds.

List<Client> clientList: List of clients for which to seek playback. Default is null, indicating all clients.
