Introduction#

DpvrDeviceManager2 is an SDK for DPVR VR all-in-one device management and control. It provides a series of operations that developers need some system permissions to perform, such as connecting to wifi, bluetooth, getting device version number, etc. At the same time, it also provides some function calls that come with Dpvr system services, such as quick calls to tools like DpvrVideoPlayer, DpvrDownloadService, etc.

DpvrDeviceManager2 uses a call method similar to Http Post request.

You can use this method to call DeviceManagerAPI:

class Params {
    lateinit var apkFilePath: String
}

fun packageManagerModuleTest() {
    val cat = "packageJobs"
    val type = "InstallPackage"
    val params = Params()
    val gson = Gson()
    params.apkFilePath = "/sdcard/DCIM/Viki.apk"
    deviceManager?.call(cat, type, gson.toJson(params))
}

Where, call is used to call the interface, its parameters are as follows:

Parameter

Function

cat

The major API category to call, such as packageJobs

type

The specific API to call, such as InstallPackage

params

The input parameters of the interface after JSON serialization

After calling the API, a corresponding jobID will be generated, and we return the call result through a ResultCallback:

interface IDeviceManagerResultListener {
    void onResult(int jobId, String result);
}

Similar to the API interface call, the parameters of the callback correspond to the JobID of the API call and the serialized return value of the call. All API calls in the global use a common listener callback.

Parameter

Function

jobID

The jobID generated by the corresponding call

result

The call result after JSON serialization

For some continuously occurring events, such as when you call the wifi or bluetooth scanning interface, there will be continuous results returned. For these non-continuous callbacks, or if you want to continuously listen to some events in the system, we return through another EventCallbck.

interface IDeviceManagerEventListener {
    void onEvent(String eventType, String eventInfo);
}

Parameter

Function

eventType

Callback event type

result

Event information after JSON serialization

Here, through a simple example, to show the initialization process and API call method of DpvrDeviceManager2 on native Android:

/*Initialization part*/
var deviceManager: IDeviceManager? = null
private val mResultListener: IDeviceManagerResultListener =
    object : IDeviceManagerResultListener.Stub() {
        override fun onResult(jobId: Int, result: String?) {

        }
    }

private val mEventListener: IDeviceManagerEventListener =
    object : IDeviceManagerEventListener.Stub(){
        override fun onEvent(eventType: String?, eventInfo: String?) {
            Log.d(TAG,"On event $eventType, $eventInfo")
        }
    }


private var connection: ServiceConnection = object : ServiceConnection {
    override fun onServiceConnected(componentName: ComponentName?, binder: IBinder?) {
        Log.d(TAG, "on service connected" + componentName?.className);
        deviceManager = IDeviceManager.Stub.asInterface(binder)
        deviceManager!!.setDeviceManagerResultListener(mResultListener)
        deviceManager!!.setDeviceManagerEventListener(mEventListener)
        mOnReadyCallback?.onReady(true)
    }

    override fun onServiceDisconnected(p0: ComponentName?) {
        Log.d(TAG, "on service disconnected")
    }
}

private fun bindService() {
    mContext.bindService(intent, connection, Service.BIND_AUTO_CREATE)
}

init {
    Log.d("fxy", "init unittest")
    bindService()
}

/*Call API*/
fun callInstallApk() {
    val cat = "packageJobs"
    val type = "InstallPackage"
    val params = Params()
    params.apkFilePath = "/sdcard/DCIM/Viki.apk"
    deviceManager?.call(cat, type, GlobalInstances.gsonAll.toJson(params))
}
