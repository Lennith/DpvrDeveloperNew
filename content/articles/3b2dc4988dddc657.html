SetAudioRecordType#

Set the sound recording format for screen casting and recording

Permission#

APP_PERMISSION_SYSTEM

Params#

property

type

default

description

isRecord

Boolean

false

Whether to record the screen audio track, true: set screen recording, false: set screen casting

setRecordType

String

property

type

default

description
