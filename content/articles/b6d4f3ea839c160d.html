通过应用配置¶

设置服务端IP和端口¶

通过adb指令：

adb shell am start com.deepoon.eggchair/.MainActivity

打开服务端设置应用。

通过填入服务端IP和端口并点击Confirm后生效。

在设置了服务器IP或者Port，RDC服务会开始自动运行。

如果需要开机自动运行，请勾选 Start when boot 选项。

如果需要自动寻找服务端，可以勾选 AUTO FIND，设置的IP和PORT将会失效，服务端开启设备发现功能后，会自动进行连接。

Note

设备发现功能需要保证服务器和客户端在同一个广播域中，并且路由器允许内网广播。

启动RDC客户端服务¶

RDC服务是一个原生Android服务，他的包名为 com.deepoon.eggchair ，服务类AndroidManifest声明如下：

<service
    android:name=".LongchenClientService"
    android:enabled="true"
    android:exported="true"
    android:persistent="true">
    <intent-filter android:priority="1000">
        <action android:name="com.deepoon.eggchair.LongchenClientService" />
    </intent-filter>
</service>

可以通过常规的启动Android Service的方法来启动RDC服务。

在RDC服务启动后，它会自动保持和服务器的连接并接收消息。

你也可以通过设置开机自动运行，保持RDC服务一直运行。

Note

由于RDC服务会始终尝试连接服务器，且不会因为息屏停止工作，因此，开启RDC服务后，可能会导致功耗变高。
