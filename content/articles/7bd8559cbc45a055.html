Device Discovery¶

Note

Device discovery only takes effect when the client has not specified a server IP and port. When the client sets server IP and port information, it will connect to the server based on the configured information.

When device discovery is enabled, the client will automatically connect to the server.

To ensure device discovery functionality, the server and client must be in the same broadcast domain, and the router must allow local network broadcasts.

If devices with different SSIDs (due to mixed-frequency Wi-Fi or topology-based multiple routers) are not in the same broadcast domain, device discovery may not work properly.
