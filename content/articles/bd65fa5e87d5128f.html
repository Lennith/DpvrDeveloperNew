Troubleshoot: Disk Not Showing

Solutions for when the P1 Max disk does not appear after connecting to a Windows PC.

01

Check Basic Connection

  • Ensure the cable supports **data transfer** (not just charging).
  • Try different USB ports (preferably rear ports on a desktop PC).
02

Verify Driver in Device Manager

Search for Device Manager in the Start menu and open it. Look for any unrecognized devices or those with a yellow exclamation mark (!).

03

Update Driver Manually

Follow these steps to manually install the MTP driver:

  • 1.
    Right-click the problematic device and select Update driver.
  • 2.
    Select Browse my computer for drivers.
  • 3.
    Select Let me pick from a list of available drivers on my computer.
  • 4.
    Select Portable Devices.
  • 5.
    Select Standard MTP Device, then MTP USB Device.
  • 6.
    Click Next and confirm the installation.
