透传消息¶

透传消息的作用是通过RDC的通信链路直接给一个指定应用发送一条消息，或者一体机端应用给服务端发送一条消息，用于开发者实现自定义功能，目前单条消息的长度不能超过1000个字节。

服务端发送¶

public void MessengerSendToClient(string toPackage, string content, List<Client> clientList = null)

string toPackage：客户端接收消息的应用。

string content：消息内容。

List<Client> clientList：接收的客户端列表，为空时所有连接的客户端会接收到消息。

服务端收到客户端消息回调¶

public delegate void OnMessageFromClient(Client client, DpvrRDCServer.ClientMessage msg);

客户端应用透传消息回调。

Client client：发生状态改变的客户端。

ClientMessage msg：客户端透传消息。

其中，ClientMessage结构体定义如下：

public class ClientMessage
{
    public string fromPackage;
    public string content;
}

string fromPackage：发送透传的应用包名。

string content：透传消息内容。

客户端透传消息使用方式¶

DpvrDeviceManagerService提供了AIDL调用后的封装 API ，方便开发者快速接入.
