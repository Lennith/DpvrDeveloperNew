BATTERY_STATE_CHANGED#

Battery status change.

class BatteryStateEvent {
    var level: Int? = 0
    var state: Int? = 0
}

Permission#

APP_PERMISSION_SYSTEM

Type name#

battery_state_changed

Property#

Int level: Battery level.

Int state: Battery status.

1: Unknown status (BATTERY_STATUS_UNKNOWN).

2: Charging (BATTERY_STATUS_CHARGING).

3: Discharging (BATTERY_STATUS_DISCHARGING).

4: Not charging (BATTERY_STATUS_NOT_CHARGING).

5: Fully charged (BATTERY_STATUS_FULL).
