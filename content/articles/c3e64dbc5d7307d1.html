VIDEO_PLAY_STATUS#

DPVR独立播放器的播放状态。

class VideoPlayStatusEvent {
    var time: Float? = 0.0f
    var videoName: String? = ""
    var videoPath: String? = ""
    var videoDisplayType: Int? = -1
    var state: String? = "STOPED"
    var duration: Float? = 0.0f
}

Permission#

APP_PERMISSION_NORMAL

Type name#

video_player_status

Property#

Float time: 视频播放进度（单位：s）。

String VideoName: 视频文件名。

String VideoPath: 视频文件路径。

Int videoDisplayType: 视频显示类型。

0: 普通2D。

1: 3D左右。

4: 3D上下。

16: 全景2D。

17: 全景左右3D。

20: 全景上下3D。

32: 180度2D。

33: 180度左右3D。

36: 180度上下3D。

64: 鱼眼2D。

65: 鱼眼左右3D。

68: 鱼眼上下3D。

128: EAC 2D。

129: EAC 左右3D。

1024: Cubemap。

String state: 视频播放状态。

“PREPARED”: 准备播放。

“BUFFERING”: 正在加载缓存。

“PLAYING”: 正在播放。

“PAUSE”: 暂停播放。

“STOPED”: 停止播放。

Float duration: 视频总时长（单位：s）。
