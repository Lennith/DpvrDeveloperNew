Copy Tool Guide

This tool is used for batch execution of tasks such as copying files, installing APKs, unzipping ZIPs, and copying OBB/Language/OTA packages.

01

Function Overview

This tool is designed for scenarios such as pre-installing applications, batch data copying, and updating resources.

  • Task Sources: Reads task configuration from an external TF card or internal storage.
  • Supported Task Types:
    • APK: Install application packages to your device (supports directories or files).
    • ZIP_UNPACK: Unzip ZIP files to the target directory.
    • FILE: Copy any directory or file to the target directory.
    • OBB: Copy application OBB files to the target directory.
    • LANGUAGE_PACKAGE: Copy language packages to the target directory.
    • OTA_PACKAGE: Copy OTA upgrade packages to the target directory (copy only, does not trigger upgrade).
  • Smart Handling: If the source is on a TF card, APK/ZIP files are first copied to a local temporary directory before installation/unzipping.
  • UI Features: Real-time display of running/completed tasks, failure logs, and Post Queue (pending install/unzip tasks). Supports one-click cache cleaning.
02

Json Configuration

Field Description
type Task type: APK, ZIP_UNPACK, FILE, OBB, LANGUAGE_PACKAGE, OTA_PACKAGE.
source Source path. Use ${EXT_SD} to represent the external TF card root directory.
dist Destination path (Automatically ignored for APK tasks).
name Task name (Optional, used for UI display).

Json Example:

[
  { "type":"APK", "source":"${EXT_SD}/AUTO_INSTALL_APPS", "name":"apps" },
  { "type":"ZIP_UNPACK", "source":"${EXT_SD}/video.zip", "dist":"/sdcard/TargetDir", "name":"videounzip" },
  { "type":"LANGUAGE_PACKAGE", "source":"${EXT_SD}/LANGUAGE", "dist":"/sdcard/Android/data", "name":"lang" },
  { "type":"FILE", "source":"${EXT_SD}/InputDir", "dist":"/sdcard/OutputDir", "name":"assets" }
]
03

Quick Start

Follow these steps to use the copy tool:

  • 1.
    Install Application: Power on the device and connect it to your computer via data cable. Copy CopyTool.apk to the device and complete the installation.
  • 2.
    Prepare Configuration: Create a file named copy_config.json, configure it according to the required tasks, and then place it in the root directory of the TF card.
  • 3.
    Copy Content: Place the content to be copied or installed onto the TF card according to the source path requirements in the copy_config.json file.
  • 4.
    Insert the TF Card: Insert the TF card into the device.
  • 5.
    Start App: Open the tool; it will automatically load the config and start tasks.
  • 6.
    Check Progress: Monitor the progress bar, success/fail counts, and any error messages on the main screen.
  • 7.
    Clean Cache: Click "Clean Cache" in the Post Queue area to remove temporary files.
