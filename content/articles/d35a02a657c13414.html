Application Control¶

Start Application¶

public void ActivityStart(string packageName, string activityName, List<Client> clientList = null)

string packageName: Package name of the application to start.

string activityName: Name of the activity within the application to start.

List<Client> clientList: List of clients for which to start the application. Default is empty, indicating all clients.

Note

The application started will be reflected in the TopPackage value of the Client.

Stop Application¶

public void ActivityStop(string packageName, List<Client> clientList = null)

string packageName: Package name of the application to stop.

List<Client> clientList: List of clients for which to stop the application. Default is empty, indicating all clients.
