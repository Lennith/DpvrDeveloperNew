Introduction¶

DPVR Remote Device Control (RDC) is a framework based on TCP/IP, using DPVR’s custom communication protocol, designed for remote control of multiple VR headsets by a single server within a local area network for DPVR VR all-in-one devices.

It is intended to support developers in the rapid development of control applications for multiple DPVR headsets using PCs, tablets, or phones simultaneously. Alternatively, one headset can serve as the server to control other headsets.

It consists of two parts:

All-in-one device end: Pre-installed system service, used to maintain the communication connection between the all-in-one device and the server, and respond to server events such as: video playback control, application switching, device switching, setting the all-in-one device and other common all-in-one control functions. Alternatively, through the pass-through function, developers can transmit data to the device via the RDC communication link.

Server end: The terminal used to control the devices. We provide an open-source demo server based on .Net, which demonstrates the encapsulation of the RDC communication protocol and the server framework based on asynchronous communication.
