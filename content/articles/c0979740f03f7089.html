SYSTEM_CONFIGURE_CHANGED#

非AndroidSettings可观察项的系统设置变化。

class SystemConfigureChangedEvent : BaseEvent(){
    var key: String? = null
    var oldValue : String? = null
    var newValue: String? = null
}

Permission#

APP_PERMISSION_NORMAL

Type name#

system_configure_changedresult

Property#

key: 键值，由 ConfigureType 定义。

oldValue: 变化前的值。

newValue: 变化后的值。
