Client Application Development¶

Client application development refers to developers using RDC pass-through messages and the RDC communication link to communicate with the server.

Developers have two methods to integrate their applications with RDC pass-through.

Warning

Due to RDC’s AIDL listener only supporting one bound Listener, the two integration methods below cannot work simultaneously.

1. AIDL Integration¶

Click here to download the AIDL files.

The AIDL interface is as follows:

interface IRemoteControllService {
    /** Send a pass-through message to the server. fromPackage is the name of the sending package,
    message is the content of the message */
    boolean sendMessageToServer(String fromPackage, String message);

    /** Get the current server connection status */
    boolean isServerConnected();

    /** Register a server pass-through message listener */
    void registerServerMessageListener(IRemoteControllerServerMessageListener listener);
}

interface IRemoteControllerServerMessageListener {
    /** Receive a server pass-through message. timeStamp is the UTC time the message was sent,
    toPackage is the name of the receiving application package, message is the
    pass-through content */
    void onMessage(long timeStamp, String toPackage, String message);
}
