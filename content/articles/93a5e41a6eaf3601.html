Video Play Configuration

This guide explains how to configure the AutoPlayDisposition.json file to control video playback behavior.

01

Configuration Parameters

Key Type Values / Description
isAutoPlay Integer 1: Enable auto-play.
0: Disable.
videoPath String Absolute path to the video (e.g., "/sdcard/demo.mp4").
videoModel Integer Playback mode:
0: Plane 2D 1: Plane 3D SBS 4: Plane 3D TAB.
16: Panoramic 360 2D 17: Panoramic 360 SBS 20: Panoramic 360 TAB.
32: Hemispheric 180 2D 33: Hemispheric 180 SBS 36: Hemispheric 180 TAB.
64: Fisheye 2D 65: Fisheye 3D SBS 68: Fisheye 3D TAB.
128: EAC 2D 129: EAC SBS 1024: Cubemap.
isSteadyOn Integer 1: Screen stays on always.
0: Screen turns off when headset is removed.
sleepTimes Integer Seconds before triggering "restart from beginning" after screen-off.
lockView Boolean true: Follows head movement.
false: Fixed in space.
distance Integer Screen distance (120 to 200). Only enabled for playback modes (0, 1, 4).
isStartBeginning Integer 1: Always start from beginning.
0: Resume from last position.
showUI Integer 1: Show playback menu/UI.
0: Hide UI.
02

JSON Example

Here is a standard configuration example for AutoPlayDisposition.json:

{
    "isAutoPlay": 1,
    "videoPath": "/sdcard/demo.mp4",
    "videoModel": 16,
    "isSteadyOn": 0,
    "sleepTimes": 10,
    "lockView": false,
    "distance": 0,
    "isStartBeginning": 1,
    "showUI": 0
}
03

Import the AutoVideoPlay folder with json file

Place AutoPlayDisposition.json file in the AutoVideoPlay folder in the device root directory (create it if it doesn't exist). The player will read this configuration upon startup.
