VideoEncryptor¶

本工具旨在帮助开发者对视频进行批处理加密，使用了Dpvr V3视频加密方式，提供相较传统AES加密流更好的性能。

Note

V3加密视频仅支持Dpvr VideoPlayer进行解密播放，且仅支持Mp4封装的视频。

如果需要对非MP4视频文件进行加密，可以使用 DPVR视频加密工具V1 进行加密。

与V1版本相比，V3视频加密在播放时，进行解密消耗的资源更少，提供了与原片播放一致的性能表现。

Warning

V3加密的授权文件仅支持V3加密的视频，V1加密的授权文件仅支持V1加密的视频，两种加密方式在底层实现上是完全不同的。 两种视频加密方式在非一体机端播放时，仅校验授权时间，不对设备进行校验。

功能¶

VideoEncryptor是一个控制台程序，提供以下三个功能： 1. 对指定路径下的MP4视频进行加密，生成加密视频文件：dpve1和mp4文件，以及对应的授权文件dpvei。 2. 对指定路径下的视频授权文件(.dpvei)进行更新，更新这些授权文件支持的设备SN和授权时间。 3. 对指定路径下的Dpvr V1视频加密的授权文件.dat进行更新，生成新的v1版本加密授权文件。

点击这里下载视频加密工具。

授权文件涵盖的认证方式包含：

  1. 根据设备序列号进行鉴权。

  2. 根据授权日期进行授权。

使用流程：

  1. 使用DpvrEncryptorUpdate.exe对指定路径下视频文件进行加密，生成加密视频文件dpve1和mp4，以及对应的授权文件dpvei。

  2. 使用DpvrVideoPlayer，进行这3个文件进行视频播放。视频播放入口为后缀为dpvei1的文件。

命令行参数¶

-e <Boolean> 或 –encrypt_dpvr_v3 <Boolean>

选择工作模式，false：加密授权文件更新，true：进行视频进行加密，默认为false。

-b <String> 或 –encrypt_key <String>

16位字符串（仅英语字母与数字），V3加密相关功能限定参数，作为播放时解密的凭据，默认为DPVR20222023HHHH。

-c <Date> 或 -encrypt_effective_date <Date>

加密有效日期，格式为：2021/01/01，进行视频加密时，默认为2099/01/01。 进行授权文件更新时，默认为原加密文件的授权有效时间。

-i <String> 或 –input_dir <String>

输入文件夹。当加密模式时，该路径为输入的MP4文件路径。当更新模式时，该路径为输入的授权文件路径。

-o <String> 或 –output_dir <String>

输出文件夹。当加密模式时，该路径为输出加密视频文件和授权文件路径。当更新模式时，该路径为输出更新后的授权文件路径。

-d <String> 或 –device_list <String>

授权设备列表文件，授权的设备列表统一放置在一个文件中，文件格式为txt，每行一个设备序列号。

-y <String> 或 –output_vei_key <String>

输出的VEI_KEY。仅V3加密模式下有效，VEI_KEY用于对授权文件更新时使用，当进行视频加密时，默认为dpvr。当进行视频加密更新时，默认沿用之前的VEI_KEY。

-k <String> 或 –input_vei_key <String>

输入的VEI_KEY，在进行V3授权文件更新时使用，在进行V3视频加密授权文件信息更新时，会先校验该值与加密时的VEI_KEY是否一致，如果不一致，则不能进行授权文件升级。

-t <String> 或 –update_type <String>

可选dat或者vei。仅在升级模式下生效，选择输出的加密授权文件类型，默认为V3加密信息vei。

-h 或者 –help

显示命令行可选参数信息。

加密工具使用方法用例¶

加密¶

DpvrEncryptorUpdate.exe --encrypt_dpvr_v3 true --input_dir d:\test --output_dir d:\testout
--device_list d:\devicelist.txt --output_vei_key test

对指定路径下MP4文件进行V3加密，并在指定输出路径下输出。

授权文件更新¶

V3授权文件更新：

DpvrEncryptorUpdate.exe --input_dir d:\test --output_dir d:\testout --update_type vei
--device_list d:\devicelist.txt --input_vei_key test --output_vei_key test

对指定文件夹下所有的授权文件（含V1和V3）进行加密授权更新，在输出路径下生成新的V3授权文件。

V1授权文件更新：

DpvrEncryptorUpdate.exe --input_dir d:\test --output_dir d:\testout --update_type dat
--device_list d:\devicelist.txt

对指定文件夹下所有的V1授权信息文件（.dat）进行加密授权更新，并在输出路径下生成新的V1授权文件。
