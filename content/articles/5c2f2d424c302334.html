Client Management¶

Client Data Structure¶

public class Client
{
    public string SN;
    public string IP;
    public int Port;
    public string TopPackage;
    public int BatteryLevel;
    public string CastRtspUrl;
    public int ConnectState;
}

string SN: Client serial number.

string IP: Client IP address.

int Port: Client port number.

string TopPackage: The topmost application package name on the client.

int BatteryLevel: Client battery level.

string CastRtspUrl: The current DPVR Cast RTSP address. It is an empty string when Cast is inactive or the address is unavailable. This value comes from the client’s heartbeat field cast_rtsp_url; it is not a synchronous result returned after sending message 1012.

int ConnectState: Client connection state, 1: Connected, 2: Disconnected.

Retrieving the Client List¶

public List<Client> ClientList;

This list contains clients that have established connections.

Retrieving a Client Instance¶

public Client GetClient(string serialNo, string ip = null)

Retrieve a client based on its serial number (SN) and IP address. The SN has higher priority than the IP. If a client matching the SN is found, it will not search by IP.

Parameters:

string serialNo: The serial number of the client to be retrieved.

string ip: The IP address of the client to be retrieved, default is null.

Return Value:

Client: The client object.
