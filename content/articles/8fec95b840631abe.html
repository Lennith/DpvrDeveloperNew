ApkEncryptor¶

本工具旨在帮助开发者快速完成应用鉴权功能的开发。 提供了应用授权文件生成工具，他提供以下两个功能：

  1. 通过APK文件和授权设备列表生成授权文件(.dpaei)。

  2. 对已有授权文件(.dpaei)进行更新。

点击这里下载授权文件生成工具。

授权文件涵盖的认证方式包含：

  1. 根据设备序列号进行鉴权。

  2. 根据授权日期进行授权。

使用流程¶

  1. 使用ApkEncryptor，生成授权文件，并记录生成授权文件时输入Encryptor_Key。

  2. 将授权文件放入机身内指定位置，作为设备的授权凭证。

  3. 调用DeviceManager的鉴权接口，传入生成的授权文件和Encryptor_Key，进行校验。

  4. 鉴权成功后，应用可以正常使用。

  5. 对于已有的.dpaei进行授权更新时，需要使用生成授权文件时的Encryptor_Key进行验证。

Attention

在应用内未调用DeviceManager鉴权接口时，应用不会被系统进行鉴权的检测。

加密工具使用方法¶

授权生成：

DpvrApkEncryptor.exe -m encrypt -i <input_apks_dir> -o <output_dpaei_dir> -k <encryptor_key> -d <device_list_file> -c <effective_date>

-m： encrypt：生成授权文件。

-i： 输入APK文件目录。

-o： 输出授权文件目录。

-k： 生成授权文件时输入的Encryptor_Key。

-d： 授权设备列表文件，授权的设备列表统一放置在一个文件中，文件格式为txt，每行一个设备序列号。

-c： 授权文件的有效期，形式为： 2021/01/01。

授权更新：

DpvrApkEncryptor.exe -m update -i <input_dpaei_dir> -o <output_dpaei_file> -k <encryptor_key> -d <device_list_file>

-m： update：更新授权文件。

-i： 输入授权文件dpaei目录。

-o： 输出授权文件目录。

-d： 授权设备列表文件，授权的设备列表统一放置在一个文件中，文件格式为txt，每行一个设备序列号。

-c： 授权文件的有效期，形式为： 2021/01/01。

设备端认证¶

将生成的授权文件放入机身内指定位置，作为设备的授权凭证。 通过DeviceManager接口调用 packageJobs/CheckApplicationAuthority 进行鉴权，返回True时为通过。具体请参考 DeviceManager文档。

参考调用（Kotlin）：

class ParamsAuthority{
    // 是否自动杀死应用，仅当调用者与被检测包名一致时才会自动关闭，默认为false。
    var autoKill : Boolean = false
    // 需要检测授权的应用包名，默认为调用者包名。
    var packageName : String? = null
    //加密时使用的encryptor_key
    var key : String = "dpvr"
    //授权文件路径，默认为/sdcard/applicationAuthority/<packageName>.dpaei
    var keyFilePath : String? = null
}

fun testAuthority(){
    val params = ParamsAuthority().apply {
        packageName = "com.dpvr.qatool"
        keyFilePath = "/sdcard/applicationAuthority/com_dpvr_qatool.dpaei"
        key = "dpvr"
    }
    val cat = "packageJobs"
    val type = "CheckApplicationAuthority"
    call(cat,type,params,null,object :ResultCallback{
        override fun onResult(result: BinderEntities.ApiFinishedResult) {
            Log.i(TAG,"result")
        }
    })
}
