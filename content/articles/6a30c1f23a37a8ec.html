WifiInfo#

Wifi信息结构。

class WifiInfo{
    var SSID: String
    var cipherType = WifiManagerModule.WIFI_CIPHER_WPA
    var frequency = WifiManagerModule.WIFI_FREQUENCY_2400
    var ip = "0.0.0.0"
    var level = 0
    var state = NetworkInfo.State.UNKNOWN.name
}

Property#

String SSID : Wifi的SSID。

String cipherType: Wifi加密类型 “WEP”: WEP加密。

“WPA”: WPA加密。

“NO_CIPHER”：未加密。

String frequency: Wifi频段 “2.4g” : 2.4g频段。

“5g” : 5g频段。

String ip: ip地址，仅在连接成功后有效。

int level : Wifi强度。

String state : 当前状态。

“CONNECTING” : 连接中。

“CONNECTED” : 已连接。

“SUSPENDED” : 挂起。

“DISCONNECTING” ： 断开连接中。

“DISCONNECTED” ： 已断开连接。

“UNKNOWN” ： 未知。
