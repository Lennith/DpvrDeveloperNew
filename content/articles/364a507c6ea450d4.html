Getting Started#

System Requirements#

DpvrDeviceManager2 needs to be on a platform that has already installed DpvrDeviceManagerSerivce to implement its API functionality.

You can use the adb command

adb shell pm list packages| findstr com.dpvr.devicemanager

to check whether the system already contains DeviceManagerService. If the command line output contains com.dpvr.devicemanager, it already has devicemanager functionality. If the return is empty, please update the system version.

Application Permissions#

While DpvrDeviceManager2 provides system functions, it also checks the caller, and each interface has different permission requirements to prevent misuse.

The caller of DeviceManager2 needs to add the following authorization information to the Application tag of their application’s AndroidManifest.xml to obtain the authorization of DeviceManangerService.

For application version authorization

<meta-data android:name="DeviceManagerKey" android:value="YOUR_KEY_HERE"></meta-data>

Using this method of authorization will authorize the current application package name and version number, and this version of the application can run on all devices that support DeviceMananger.

For specified channel firmware authorization

<meta-data android:name="DeviceManagerPlatformKey" android:value="YOUR_KEY_HERE"></meta-data>

Using this method of authorization will authorize the application package name on the specified custom channel firmware, without checking the version number.

When both types of authorization exist at the same time, the highest permission that can be obtained on the corresponding system will be used.

Currently, you need to contact DPVR’s project manager to obtain a DeviceManagerKey with normal or higher permissions.

Document Description#

The interfaces of DpvrDeviceManager2 are divided into two parts

The first part is the non-specific business function interface, which is used to initialize the connection between the application and DeviceManager, and set callbacks, which can be explained in the SDK platform document below.

The second part is the functional interface provided by DeviceManager. See api list.
