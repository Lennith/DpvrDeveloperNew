StartScan#

开始进行WifiDisplay的扫描，Api回调会返回调用接口瞬间已知的WifiDisplay，后续的新设备会通过WIFI_DISPLAY_SCAN_RESULT事件进行通知。当调用ConnectWifiDisplay接口时，会停止WifiDisplay扫描。

Support Version#

10011

Permission#

APP_PERMISSION_SYSTEM

Event#

WIFI_DISPLAY_SCAN_RESULT

Params#

property

type

default

description

duration

Int

10 * 1000

扫描时长，当尝试连接时会中断当前扫描。

Result#

property

type

default

description

list

List<WifiDisplayDeviceInfo>

null

扫描结果信息 WifiDisplayDeviceInfo 列表。
