Release Note#

2024-04-30 V10011#

  1. Added WifiDisplay-related interfaces and events to control the system’s WifiDisplay functionality.

  2. Added Sensor-related interfaces.

  3. Added descriptions of supported versions for some interfaces in the documentation.

  4. Fixed some documentation errors.

  5. Added demos of some module functions in the documentation.

  6. Changed the name of the CheckDpvrMirraCast interface to CheckDpvrMiraCast. The old interface name, if used, remains compatible.

  7. Fixed the issue where the RestoreDpnLauncher interface reported an error when passing an empty parameter.

  8. Added the ‘autoKillDelay’ parameter to the CheckApplicationAuthority interface to delay application termination.

  9. The ConnectBluetoothDevice interface no longer disconnects an existing connection and reconnects when attempting to connect to an already connected device.

  10. When GetAppInfoByPackageName detects an uninstalled app, it no longer returns a result through a parameter error. Instead, a new error is used.

  11. Fixed the issue where the ConnectWifi interface returned an SSID not found error when using a password with fewer than 8 characters. A new error is now returned in such cases.

  12. Fixed the issue where the CopyFiles interface failed to return correctly when the source path did not exist.

  13. Fixed the issue where remotecontrolJobs/IsServerConnected interface always returned that the server was not connected when it was not initialized.

2024-04-12 V10010#

  1. Added support interface for Remote Device Control service, remotecontrolJobs.

  2. Added inter-application communication interface, messageJobs.

  3. Added interface for monitoring system property changes, systemJobs/RegisterConfigureObserver, systemJobs/unRegisterConfigureObserver.

  4. Added interface for getting the current foreground application, activityJobs/GetTopPackageName.

  5. Added interface for checking whether the current screen is on, batteryJobs/IsScreenOn.

  6. Added OTA package download cancellation interface, otaJobs/CancelDownload.

  7. Added Dpvr application authorization check interface, packageJobs/CheckApplicationAuthority.
