GestureSdk Beginner Guide (English)

1. What this guide is for

This guide helps new Unity developers quickly run GestureSdk after importing the package:

  • Camera preview
  • Gesture callbacks
  • Sphere interaction demo

Scope:

  • Assets/GestureSdk

2. Prerequisites

Before import:

  1. Unity has Android Build Support installed (SDK/NDK/OpenJDK).
  2. Target platform is switched to Android (File -> Build Settings -> Android -> Switch Platform).
  3. Android device is connected with USB debugging enabled (adb devices works).

3. Import package

If you receive a .unitypackage:

  1. Open your Unity project.
  2. Click Assets -> Import Package -> Custom Package....
  3. Select the package and import all files.

After import, verify these folders exist:

  • Assets/GestureSdk/Scripts
  • Assets/GestureSdk/Scenes
  • Assets/GestureSdk/Materials
  • Assets/Plugins/Android

4. Fast start (recommended)

  1. Open Assets/GestureSdk/Scenes/SampleScene.unity.
  2. Connect Android device.
  3. Build And Run.

Expected result:

  • Camera preview is visible in scene.
  • Gesture interactions are working (sphere show/scale/color/position).

5. Manual setup (from scratch)

If you integrate into your own scene:

  1. Create empty object CameraManagerRoot, attach CameraManager.cs.
  2. Create a UI RawImage, name it CameraImage.
  3. Assign CameraImage to CameraManager.cam.
  4. Create a sphere object, name it GestureSphere.
  5. Create empty object GestureLogic, attach GestureTest.cs.
  6. Assign references on GestureTest:
    • cameraManager -> scene CameraManager
    • sphereObject -> GestureSphere
    • cameraImageRect -> CameraImage RectTransform
    • sceneCamera -> rendering camera (Camera.main fallback if empty)

6. Demo gesture behavior

Current demo logic:

  1. V_SIGN
    • Activates sphere.
    • Updates sphere position once using ROI center.
  2. OPEN_PALM
    • Scale up one step.
  3. FIST
    • Scale down one step.
  4. THUMBS_UP
    • Random sphere color.

7. Important parameters

7.1 CameraManager

Common fields:

  • cameraWidth / cameraHeight / cameraFps
  • gesturePreset
  • tickFps
  • numHands
  • inputRotation
  • inputScaleMode
  • fenceMode
  • fenceShortWaitMs

Recommended stable defaults:

  • tickFps = 5
  • numHands = 1
  • inputRotation = CCW_90
  • inputScaleMode = LETTERBOX
  • fenceMode = AUTO
  • fenceShortWaitMs = 0

7.2 GestureTest

  • scaleStepFactor: scale delta per trigger
  • maxScaleSteps: max scale steps
  • gestureCooldownSeconds: trigger cooldown
  • zDistanceFromCameraImage: sphere depth offset from CameraImage plane (camera-space)

8. Position mapping note (sphere)

Current mapping rule:

  1. Use roi center from gesture JSON.
  2. Apply X mirror compensation (mappedX = 1 - centerX).
  3. Keep Y in current scene direction (mappedY = centerY).
  4. Map to CameraImage local position and then world position.
  5. Compute final depth in camera space (move toward camera by zDistanceFromCameraImage), not by direct world z subtraction.

9. Troubleshooting

9.1 No camera preview

Check:

  1. Running on Android device (not only in editor).
  2. AAR files exist under Assets/Plugins/Android.
  3. Camera permission is granted.
  4. Unity Multithreaded Rendering is disabled (Player Settings > Other Settings > Rendering).

9.2 Camera works but no gestures

Check:

  1. CameraManager initialization is successful.
  2. Gesture parameters were not unintentionally changed.
  3. Callback logs contain continuous seq.

9.3 Sphere position is clearly off

Check:

  1. cameraImageRect points to the actual preview image.
  2. sceneCamera is the actual rendering camera.
  3. zDistanceFromCameraImage is tuned for your scene scale.

This guide is intended to help new teammates integrate and run GestureSdk quickly in existing Unity projects.

The sources describe zDistanceFromCameraImage depth and calculation differently. Their original descriptions are retained; no algorithm is silently changed.
