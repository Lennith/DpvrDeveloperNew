CAST_STATE_CHANGED#

Screen casting/recording/screenshot status change.

class CastStateEvent {
    var isCasting = false
    var isRecoding = false
    var isMiracast = false
    var isShot = false
}

Permission#

APP_PERMISSION_NORMAL

Type name#

dpvr_cast_state

Property#

Boolean isCasting: Whether Dpvr screen casting is in progress.

Boolean isRecording: Whether screen recording is in progress.

Boolean isMiracast: Whether Android screen casting is in progress.

Boolean isShot: Whether screenshot is in progress.
