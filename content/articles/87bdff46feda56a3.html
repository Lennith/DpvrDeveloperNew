ApiFinishedResult#

The execution result of the Api.

class ApiFinishedResult {
    var jobId = 0
    var returnCode = 0
    var result: String? = null
    var error: String? = null
}

Property#

int jobId : The jobId of the Call corresponding to this result.

int returnCode: The execution result of the Api, 0: successful execution, 1: task was cancelled, 2: call error.

String result : The Json serialized string of the Api execution result, corresponding to the Result definition in the Api document.

String : When the Api call fails, it is used to display the error reason.
