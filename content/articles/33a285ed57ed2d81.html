CopyFiles#

批量复制拷贝文件，该接口权限不向普通开发者开放，需要联系dpvr fae获取。当Src为目录时，Dst必须为目录。 Src为文件时，Dst必须为文件路径。

Permission#

APP_PERMISSION_ADMINISTOR

Params#

property

type

default

description

sourcePath

String

文件存在的地址

distPath

String

复制的目标地址

forceCopy

Boolean

false

是否覆盖重写

Result#

property

type

default

description

fileCopiedNum

Int

0

复制的文件数量

failedFileList

List<String>

null

复制失败的文件列表
