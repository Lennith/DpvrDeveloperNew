StartScan#

Start scanning for WifiDisplay. The Api callback will return the WifiDisplay known at the moment of calling the interface, and subsequent new devices will be notified through the WIFI_DISPLAY_SCAN_RESULT event. When the ConnectWifiDisplay interface is called, the WifiDisplay scan will stop.

Permission#

APP_PERMISSION_SYSTEM

Event#

WIFI_DISPLAY_SCAN_RESULT

Params#

property

type

default

description

duration

Int

10 * 1000

Scan duration, the current scan will be interrupted when trying to connect.

Scan result information WifiDisplayDeviceInfo list.
