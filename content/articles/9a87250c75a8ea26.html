客户端应用开发¶

客户端应用开指开发者基于RDC透传消息，使用RDC通信链路，与服务器进行通信。

开发者有两种方法可以使应用接入RDC透传。

Warning

由于RDC的AIDL的监听仅支持一个绑定的Listener，因此，下文两种接入方式无法同时工作。

1. AIDL 接入¶

点击这里下载AIDL文件。

AIDL接口如下：

interface IRemoteControllService {
    /** 发送透传消息给服务器，fromPackage 发送消息的包名，message 发送的消息内容 */
    boolean sendMessageToServer(String fromPackage, String message);

    /** 获取当前服务器连接状态 */
    boolean isServerConnected();

    /** 注册服务端透传消息监听 */
    void registerServerMessageListener(IRemoteControllerServerMessageListener listener);
}

interface IRemoteControllerServerMessageListener {
    /** 收到服务器透传消息，timeStamp 发送消息的UTC时间， toPackage 接收透传的应用包名， message 透传内容。*/
    void onMessage(long timeStamp, String toPackage, String message);
}
