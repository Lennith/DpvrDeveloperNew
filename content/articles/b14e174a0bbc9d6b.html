配置文件设置¶

通过在一体机根目录下放置配置文件同样可以进行RDC一体机端的配置。

在一体机设备根目录下放置 persist_settings 文件，可以用来进行Dpvr的预加载配置。

对于RDC相关我们可以增加下面这些设置。

{
    "SettingKey":0,
    "WifiConfig":{
        "password":"Dpvr@2022",
        "ssid":"DPVR_Office",
        "type":"WEP"
    },
    "SettingConfig":
    [
        {
            "Key":"LCServerIP",
            "SettingType":"global",
            "Value":"192.168.1.1",
            "ValueType":"string"
        },
        {
            "Key":"LCServerPort",
            "SettingType":"global",
            "Value":"1000",
            "ValueType":"int"
        },
        {
            "Key":"dp_auto_start_remote_control",
            "SettingType":"int",
            "Value":"1",
            "ValueType":"global"
        }
    ]
}

其中， SettingConfig 为预加载Settings，会在每次开机时自动加载。

LCServerIP : 为远程控制服务器的IP地址。

LCServerPort : 为远程控制服务器的端口号。

dp_auto_start_remote_control : 是否自动启动远程控制。

Note

Value 设置为1时，表示开机自动开启RDC服务，为0表示不自动开启。

WifiConfig : 设置开机自动连接的WIFI，其中 ssid 为WIFI名称， password 为WIFI密码， type 为WIFI加密方式，目前支持 WEP 和 WPA 两种加密方式。

Note

AutoWifi连接逻辑是在开机后未连接Wifi时，始终尝试去连接该Wifi。
