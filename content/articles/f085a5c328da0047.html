BLUETOOTH_CONNECTED_CHANGE#

Bluetooth connection status change.

class BluetoothConnectedStateEvent {
    var state: String? = null
    var bluetoothInfo: String? = null
}

Permission#

APP_PERMISSION_SYSTEM

Type name#

bluetooth_connected_state_changed

Property#

String state: Bluetooth status.

Connected: Connected.

Disconnected: Disconnected.

String bluetoothInfo: Bluetooth information after the change, Json serialization of DpvrBluetoothDevice
