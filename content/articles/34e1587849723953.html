SetWifiEnable#

Enable or disable Wifi. Please note that this interface does not take effect immediately after the call is successful. After the interface call is completed, it may still take about 2 seconds to complete the switch operation at the driver level.

Permission#

APP_PERMISSION_NORAML

Params#

property

type

default

description

isEnable

Boolean

false

true to turn on WiFi, false to turn off WiFi
