Configuration File Settings¶

You can also configure the RDC all-in-one device by placing a configuration file in the root directory of the device.

Place the persist_settings file in the root directory of the all-in-one device for Dpvr preloaded configuration.

For RDC-related settings, you can add the following configurations:

{
    "SettingKey":0,
    "WifiConfig":{
        "password":"Dpvr@2022",
        "ssid":"DPVR_Office",
        "type":"WEP"
    },
    "SettingConfig":
    [
        {
            "Key":"LCServerIP",
            "SettingType":"global",
            "Value":"192.168.1.1",
            "ValueType":"string"
        },
        {
            "Key":"LCServerPort",
            "SettingType":"global",
            "Value":"1000",
            "ValueType":"int"
        },
        {
            "Key":"dp_auto_start_remote_control",
            "SettingType":"int",
            "Value":"1",
            "ValueType":"global"
        }
    ]
}

Here, SettingConfig is the preloaded Settings, which will be automatically loaded every time the device starts.

LCServerIP : The IP address of the remote control server.

LCServerPort : The port number of the remote control server.

dp_auto_start_remote_control : Whether to start remote control automatically.

Note

Setting Value to 1 means the RDC service will start automatically at boot; 0 means it will not start automatically.

WifiConfig : Sets the WiFi to connect automatically at boot. ssid is the WiFi name, password is the WiFi password, and type is the WiFi encryption type. Currently, WEP and WPA encryption types are supported.

Note

The AutoWifi connection logic will continuously attempt to connect to the specified WiFi if no WiFi is connected at boot.
