设备管理¶

按键屏蔽状态数据结构：¶

public class InputState
{
    public bool HomeKeyBlock = false;
    public bool PowerKeyBlock = false;
    public bool TouchPadBlock = false;
    public bool VolumeKeyBlock = false;
    public bool BackKeyBlock = false;
}

bool HomeKeyBlock：屏蔽Home键，含手柄Home键短按。

bool PowerKeyBlock：屏蔽Power键短按，长按10秒关机无法通过该项屏蔽。

bool TouchPadBlock：屏蔽机身触摸板。

bool VolumeKeyBlock：屏蔽音量键。

bool BackKeyBlock：屏蔽Back键，含手柄Back键。

按键屏蔽与解除屏蔽¶

public void DeviceSetInputState(InputState states, List<Client> clientList = null)

InputState states：需要设置的按键状态。

List<Client> clientList: 指定要关闭的应用的客户端列表，默认为空，表示所有客户端。

public void DeviceSetVolume(int value, List<Client> clientList = null)

int value：音量值，范围0-100。

List<Client> clientList: 指定要关闭的应用的客户端列表，默认为空，表示所有客户端。

开启 DPVR Cast¶

public void DeviceStartDpvrCast(List<Client> clientList = null)

向指定客户端发送 1012 消息，请求设备通过 DMS 开启 DPVR Cast RTSP 流。

List<Client> clientList：指定客户端列表，默认为空，表示所有客户端。

关闭 DPVR Cast¶

public void DeviceStopDpvrCast(List<Client> clientList = null)

向指定客户端发送 1013 消息，请求设备通过 DMS 关闭 DPVR Cast RTSP 流。

List<Client> clientList：指定客户端列表，默认为空，表示所有客户端。

实际是否已经开始 Cast，需要读取客户端后续心跳中的 CastRtspUrl；收到空字符串表示当前没有可用的 Cast 地址。
