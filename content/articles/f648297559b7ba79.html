BluetoothScanResult#

Bluetooth scan result.

class BluetoothScanResult {
    var name: String? = null
    var address: String? = null
    var deviceClass = 0
    var rssi = 0
    var type = 0
}

Property#

String name: Bluetooth device name.

String address: MAC address of the Bluetooth device.

int deviceClass: Bluetooth device class constant.

0: Mixed device (MISC).

1024: Audio and video devices (AUDIO_VIDEO).

256: Computer devices (COMPUTER).

2304: Health monitoring devices (HEALTH).

1536: Imaging devices (IMAGING).

768: Networking devices (NETWORKING).

1280: Peripheral devices (PERIPHERAL).

512: Mobile devices (PHONE).

2048: Toy devices (TOY).

1792: Wearable devices (WEARABLE).

7936: Unclassified (UNCATEGORIZED).

int rssi: Bluetooth signal strength.

int type: Bluetooth type.

0: Unknown type (DEVICE_TYPE_UNKNOWN).

1: Classic - BR / EDR devices (DEVICE_TYPE_CLASSIC).

2: Low energy - LE-only (DEVICE_TYPE_LE).

3: Dual mode - BR / EDR / LE (DEVICE_TYPE_DUAL).
