WIFI_DISPLAY_CONNECTION_CHANGED#

WifiDisplay连接变化，目前仅有连接和断开。

class WifiDisplayConnectionChanged{
    var connected : Boolean = false
    var deviceInfo : WifiDisplayDeviceInfo? = null
}

Permission#

APP_PERMISSION_NORMAL

Type name#

wifi_display_connection_changed

Property#

Boolean connected: 连接或者断开，True表示新的连接，False表示连接断开。

WifiDisplayDeviceInfo deviceInfo: WifiDisplayDeviceInfo 列表的Json序列化。
