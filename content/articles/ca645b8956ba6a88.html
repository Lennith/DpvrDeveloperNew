BATTERY_STATE_CHANGED#

电池状态变化。

class BatteryStateEvent {
    var level: Int? = 0
    var state: Int? = 0
}

Permission#

APP_PERMISSION_SYSTEM

Type name#

battery_state_changed

Property#

Int level: 电池电量。

Int state: 电池状态。

1: 未知状态（BATTERY_STATUS_UNKNOWN）。

2: 正在充电（BATTERY_STATUS_CHARGING）。

3: 放电中（BATTERY_STATUS_DISCHARGING）。

4: 未充电（BATTERY_STATUS_NOT_CHARGING）。

5: 已充满电（BATTERY_STATUS_FULL）。
