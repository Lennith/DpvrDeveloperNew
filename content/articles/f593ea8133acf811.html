WIFI_STATE_CHANGED#

Wifi status change.

class WifiStateChangedEvent {
    var state: String? = null
    var changedWifiInfo: String? = null
    var reason: String? = null
}

Permission#

APP_PERMISSION_SYSTEM

Type name#

wifi_state_changed

Property#

String state: Status of Wifi after the change.

“CONNECTING” : Connecting.

“CONNECTED” : Connected.

“SUSPENDED” : Suspended.

“DISCONNECTING” : Disconnecting.

“DISCONNECTED” : Disconnected.

“UNKNOWN” : Unknown.

String changedWifiInfo : Wifi information after the change. Json serialization of WifiInfo

String reason : If disconnected, the reason for disconnection.
