WIFI_STATE_CHANGED#

Wifi状态变化。

class WifiStateChangedEvent {
    var state: String? = null
    var changedWifiInfo: String? = null
    var reason: String? = null
}

Permission#

APP_PERMISSION_SYSTEM

Type name#

wifi_state_changed

Property#

String state: Wifi变化后的状态。

“CONNECTING” : 连接中。

“CONNECTED” : 已连接。

“SUSPENDED” : 挂起。

“DISCONNECTING” ： 断开连接中。

“DISCONNECTED” ： 已断开连接。

“UNKNOWN” ： 未知。

String changedWifiInfo : 变动后的Wifi信息。 WifiInfo 的Json序列化。

String reason : 如果是断开连接，断开连接的原因。
