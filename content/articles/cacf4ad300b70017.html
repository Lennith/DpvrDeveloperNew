Pass-through message¶

The function of pass-through messages is to directly send a message to a specified application through the RDC communication link, or an application on the VR headset to send a message to the server, which is used by developers to implement custom functions.The length of a single message cannot exceed 1000 bytes.

Server-side Sending¶

public void MessengerSendToClient(string toPackage, string content, List<Client> clientList = null)

string toPackage: The application package that clients will receive the message.

string content: The content of the message.

List<Client> clientList: List of clients to receive the message. If null, all connected clients receive the message.

Server-side Callback for Client Messages¶

public delegate void OnMessage(Client client, DpvrRDCServer.ClientMessage msg);

Callback for client applications to forward messages.

Client client: The client where the state change occurred.

ClientMessage msg: Message forwarded from the client.

Where the ClientMessage structure is defined as follows:

public class ClientMessage
{
    public string fromPackage;
    public string content;
}

string fromPackage: Package name of the sending application for the forwarded message.

string content: Content of the forwarded message.

Usage of Client Message Sending¶

DpvrDeviceManagerService provides encapsulation after AIDL call API , facilitating quick integration for developers.
