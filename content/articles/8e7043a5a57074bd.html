GestureSdk 开发说明（新手可直接使用）

1. 这份文档是干什么的

这份文档用于指导新同学把 GestureSdk 以 Unity package 形式导入项目后，快速跑通：

  • 相机画面预览
  • 手势识别回调
  • 示例球体联动效果

适用目录：

  • Assets/GestureSdk

2. 导入前准备

请先确认：

  1. Unity 已安装 Android Build Support（含 SDK/NDK/OpenJDK）。
  2. 项目平台切到 Android（File -> Build Settings -> Android -> Switch Platform）。
  3. 真机已打开 USB 调试，并可通过 adb devices 识别。

3. 如何导入 package

如果你拿到的是 .unitypackage：

  1. 打开 Unity 工程。
  2. 点击 Assets -> Import Package -> Custom Package...。
  3. 选择 package 文件，全部勾选导入。

导入后应至少包含这些目录：

  • Assets/GestureSdk/Scripts
  • Assets/GestureSdk/Scenes
  • Assets/GestureSdk/Materials
  • Assets/Plugins/Android

4. 一键体验（推荐）

最简单方式：

  1. 打开场景 Assets/GestureSdk/Scenes/SampleScene.unity。
  2. 连接 Android 设备。
  3. Build And Run。

启动后你应该看到：

  • 场景中有相机预览画面。
  • 做手势后有识别回调效果（球体显隐/缩放/变色/定位）。

5. 场景手动搭建步骤（从零搭建）

如果你要在自己场景中接入，按下面做：

  1. 创建一个空物体 CameraManagerRoot，挂载 CameraManager.cs。
  2. 创建一个 UI RawImage，命名建议 CameraImage。
  3. 在 CameraManager 的 cam 字段里拖入这个 RawImage。
  4. 创建一个球体（Sphere），命名建议 GestureSphere。
  5. 创建一个空物体 GestureLogic，挂载 GestureTest.cs。
  6. 在 GestureTest 上绑定：
    • cameraManager -> 场景中的 CameraManager 组件
    • sphereObject -> GestureSphere
    • cameraImageRect -> CameraImage 的 RectTransform
    • sceneCamera -> 场景主相机（不填会自动用 Camera.main）

6. 示例手势行为

当前示例逻辑如下：

  1. V_SIGN
    • 激活球体
    • 按手势位置更新球体坐标（只在识别到 V_SIGN 时更新一次）
  2. OPEN_PALM
    • 球体放大一档
  3. FIST
    • 球体缩小一档
  4. THUMBS_UP
    • 球体随机换色

7. 关键参数说明

7.1 CameraManager（识别与相机参数）

常用字段：

  • cameraWidth / cameraHeight / cameraFps
  • gesturePreset
  • tickFps
  • numHands
  • inputRotation
  • inputScaleMode
  • fenceMode
  • fenceShortWaitMs

推荐稳定默认值：

  • tickFps = 5
  • numHands = 1
  • inputRotation = CCW_90
  • inputScaleMode = LETTERBOX
  • fenceMode = AUTO
  • fenceShortWaitMs = 0

7.2 GestureTest（示例交互参数）

  • scaleStepFactor：每次放大/缩小幅度
  • maxScaleSteps：最大缩放档位
  • gestureCooldownSeconds：手势触发冷却
  • zDistanceFromCameraImage：球体相对 CameraImage 的深度距离（按相机空间计算）

8. 当前位置映射规则（球体定位）

当前球体定位规则：

  1. 使用手势回调 JSON 中 roi 的中心点作为目标。
  2. X 轴做一次镜像补偿（用于对齐当前预览链路）。
  3. Y 轴按当前场景方向直接映射。
  4. 深度不是直接减世界坐标，而是：
    • 先取 CameraImage 平面点
    • 再在相机坐标系里向相机方向移动固定距离

这能保证球体在屏幕位置稳定，且深度关系更合理。

9. 常见问题排查

9.1 没有相机画面

请检查：

  1. 是否在 Android 真机运行（编辑器内无法走 Android Camera/AAR）。
  2. Assets/Plugins/Android 下 AAR 是否完整。
  3. 是否已授予相机权限。
  4. 是否已关闭 Unity 的 Multithreaded Rendering（Player Settings > Other Settings > Rendering）。

9.2 有画面但没有手势结果

请检查：

  1. CameraManager 是否正常初始化。
  2. tickFps/numHands/inputRotation 是否被误改。
  3. 手势回调日志中是否有连续 seq。

9.3 球体位置偏移明显

请检查：

  1. GestureTest.cameraImageRect 是否绑定到了真实预览用的 CameraImage。
  2. sceneCamera 是否是当前渲染该画面的相机。
  3. zDistanceFromCameraImage 是否过大/过小。

以上步骤用于帮助新同学在现有工程中快速接入并跑通 GestureSdk。

不同说明中的 zDistanceFromCameraImage 距离语义与计算表述存在差异；正文按各来源保留，未统一改写算法。
