应用控制¶

开启应用¶

public void ActivityStart(string packageName, string activityName, List<Client> clientList = null)

string packageName：要开启的应用包名。

string activityName：要开启的应用的Activity名称。

List<Client> clientList：指定要开启的应用的客户端列表，默认为空，表示所有客户端。

Note

开启后的应用会在Client的TopPackage的值上体现。

关闭应用¶

public void ActivityStop(string packageName, List<Client> clientList = null)

string packageName：要关闭的应用包名。

List<Client> clientList: 指定要关闭的应用的客户端列表，默认为空，表示所有客户端。
