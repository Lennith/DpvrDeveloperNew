Introduction#

DpvrDeviceManager2是一套用于DPVR VR一体机设备管理和控制的SDK。 它提供了一系列开发者需要一些系统权限才能够进行的操作，例如连接wifi、蓝牙、获取设备版本号等。 同时，也提供了一些Dpvr系统服务中自带的功能调用，例如，DpvrVideoPlayer，DpvrDownloadService等工具的快捷调用。

DpvrDeviceManager2使用了类似于Http Post请求的调用方式。

你可以通过这样的方法来调用DeviceManagerAPI：

class Params {
    lateinit var apkFilePath: String
}

fun packageManagerModuleTest() {
    val cat = "packageJobs"
    val type = "InstallPackage"
    val params = Params()
    val gson = Gson()
    params.apkFilePath = "/sdcard/DCIM/Viki.apk"
    deviceManager?.call(cat, type, gson.toJson(params))
}

其中，call用来调用接口，它的参数如下：

参数

作用

cat

调用的API大类，如packageJobs

type

调用的具体API，如InstallPackage

params

JSON序列化后的接口输入参数

在调用API后，会生成一个对应的jobID，我们通过一个ResultCallback来返回调用的结果：

interface IDeviceManagerResultListener {
    void onResult(int jobId, String result);
}

与调用API接口call类似，回调的参数对应为API调用的JobID和序列化后的调用返回值。全局中所有的API调用共用一个监听回调。

参数

作用

jobID

回调对应的call生成的jobID

result

JSON序列化后的调用结果

对于一些持续发生的事件，例如你调用扫描wifi或者蓝牙接口时时，会有持续不断的结果进行返回，对于这些非持续回调，或者希望对系统中某些事件进行持续监听的回调，我们通过另一种EventCallbck来返回。

interface IDeviceManagerEventListener {
    void onEvent(String eventType, String eventInfo);
}

参数

作用

eventType

回调事件类型

result

JSON序列化后的事件信息

这里通过一个简单的例子，来展现下DpvrDeviceManager2在原生安卓上的初始化流程与API调用方式：

/*初始化部分*/
var deviceManager: IDeviceManager? = null
private val mResultListener: IDeviceManagerResultListener =
    object : IDeviceManagerResultListener.Stub() {
        override fun onResult(jobId: Int, result: String?) {

        }
    }

private val mEventListener: IDeviceManagerEventListener =
    object : IDeviceManagerEventListener.Stub(){
        override fun onEvent(eventType: String?, eventInfo: String?) {
            Log.d(TAG,"On event $eventType, $eventInfo")
        }
    }


private var connection: ServiceConnection = object : ServiceConnection {
    override fun onServiceConnected(componentName: ComponentName?, binder: IBinder?) {
        Log.d(TAG, "on service connected" + componentName?.className);
        deviceManager = IDeviceManager.Stub.asInterface(binder)
        deviceManager!!.setDeviceManagerResultListener(mResultListener)
        deviceManager!!.setDeviceManagerEventListener(mEventListener)
        mOnReadyCallback?.onReady(true)
    }

    override fun onServiceDisconnected(p0: ComponentName?) {
        Log.d(TAG, "on service disconnected")
    }
}

private fun bindService() {
    mContext.bindService(intent, connection, Service.BIND_AUTO_CREATE)
}

init {
    Log.d("fxy", "init unittest")
    bindService()
}

/*调用API*/
fun callInstallApk() {
    val cat = "packageJobs"
    val type = "InstallPackage"
    val params = Params()
    params.apkFilePath = "/sdcard/DCIM/Viki.apk"
    deviceManager?.call(cat, type, GlobalInstances.gsonAll.toJson(params))
}
