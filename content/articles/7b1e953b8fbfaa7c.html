DpvrBluetoothDevice#

Bluetooth device information.

class DpvrBluetoothDevice {
    var name: String? = null
    var address: String? = null
    var type = 0
    var state = 0
}

Property#

String name:The name of the Bluetooth device.

String address:The MAC address of the Bluetooth device.

int type: Bluetooth type.

0 : Unknown type (DEVICE_TYPE_UNKNOWN).

1 : Classic - BR / EDR devices (DEVICE_TYPE_CLASSIC).

2 : Low energy - LE-only (DEVICE_TYPE_LE).

3 : Dual mode - BR / EDR / LE (DEVICE_TYPE_DUAL).

int state : Bluetooth pairing status.

10 : Not paired.

11 : Pairing in progress.

12 : Paired.
