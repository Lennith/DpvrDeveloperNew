CheckApplicationAuthority#

Check whether the application has been authorized. The caller checks the corresponding authorization information based on the input Key (used for encryption) and KeyFilePath, and needs to use the Dpvr application authorization tool for authorization. If the caller is the same as the package being checked, the application can be automatically closed. The authorization file path can be specified, with the default value being the package name encryption information file generated under /sdcard/sdcard/applicationAuthority/.

APP_PERMISSION_NORMAL
