WifiScanResult#

WIFI扫描结果。

class WifiScanResult {
    var cipherType = WifiManagerModule.WIFI_CIPHER_NO_CIPHER
    var ssid = ""
    var level = 0
    var frequency = WifiManagerModule.WIFI_FREQUENCY_2400
}

Property#

String cipherType: Wifi加密类型。

“WEP”: WEP加密。

“WPA”: WPA加密。

“NO_CIPHER”：未加密。

String ssid: Wifi名称。

int level: Wifi强度。

String frequency: Wifi频段

“2.4g” : 2.4g频段。

“5g” : 5g频段。
