视频播放控制¶

视频渲染格式类型¶

public static class VideoRenderType
{
    public static int NORMAL_2D = 0;
    public static int NORMAL_3D_LEFT_RIGHT = 1;
    public static int NORMAL_3D_UP_DOWN = 2;
    public static int VR_180_2D = 3;
    public static int VR_180_3D_LEFT_RIGHT = 4;
    public static int VR_180_3D_UP_DOWN = 5;
    public static int VR_360_2D = 6;
    public static int VR_360_3D_LEFT_RIGHT = 7;
    public static int VR_360_3D_UP_DOWN = 8;
}

NORMAL_2D：标准2D视频。

NORMAL_3D_LEFT_RIGHT：左右3D视频。

NORMAL_3D_UP_DOWN：上下3D视频。

VR_180_2D：180度VR视频。

VR_180_3D_LEFT_RIGHT：左右180度VR视频。

VR_180_3D_UP_DOWN：上下180度VR视频。

VR_360_2D：360度VR视频。

VR_360_3D_LEFT_RIGHT：360度左右3DVR视频。

VR_360_3D_UP_DOWN：360度上下3DVR视频。

开始播放¶

public void VideoStart(string filePath, int mode = -1, bool startWhenPrepared = false, List<Client> clientList = null)

string filePath：视频地址。

int mode：渲染格式，对应上文的渲染格式，默认为自动选取。

bool startWhenPrepared：完成加载后自动播放，默认为false，需要恢复播放需要调用VideoResume接口。

List<Client> clientList：指定播放的客户端列表，默认为null，表示所有客户端。

停止播放¶

public void VideoStop(List<Client> clientList = null)

List<Client> clientList：指定停止播放的客户端列表，默认为null，表示所有客户端。

Note

客户端按最近一次 1002 播放消息选择停止路由：使用 DPVR 播放器时向 com.dpvr.videoplayer.VIDEOPLAYERCONTROLLER 发送停止指令，回落到 DpnLauncher 时向 com.deepoon.dpnlauncher.PLAY_CONTROL 发送 controltype=playcommand、operation=stop。该接口不影响 RDC 连接；停止后是否退出播放器界面由播放器应用自身决定。

暂停播放¶

public void VideoPause(List<Client> clientList = null)

List<Client> clientList：指定暂停播放的客户端列表，默认为null，表示所有客户端。

恢复播放¶

public void VideoResume(int delay = 0, List<Client> clientList = null)

int delay：恢复播放的延迟时间，单位为秒，默认为0。服务端会将该值加到当前时间，换算为统一起播时刻（PlayTime，格式 yyyy-MM-dd-HH-mm-ss）下发，所有设备在该时刻同时恢复播放；设备当前时间已过该时刻时收到命令会立即播放。使用定时恢复时，请确保设备系统时间与服务端一致，多设备同步精度约为 ±1 秒。

List<Client> clientList：指定恢复播放的客户端列表，默认为null，表示所有客户端。

跳转播放¶

public void VideoSeek(int time, List<Client> clientList = null)

int time：跳转播放的位置，单位为秒。

List<Client> clientList：指定跳转播放的客户端列表，默认为null，表示所有客户端。
