BluetoothScanResult#

蓝牙扫描结果。

class BluetoothScanResult {
    var name: String? = null
    var address: String? = null
    var deviceClass = 0
    var rssi = 0
    var type = 0
}

Property#

String name: 蓝牙设备名称。

String address: 蓝牙设备的mac地址。

int deviceClass: 蓝牙设备类常量。

0: 混合设备（MISC）。

1024: 音视频设备（AUDIO_VIDEO）。

256: 电脑设备（COMPUTER）。

2304: 健康监测设备（HEALTH）。

1536: 影像设备（IMAGING）。

768: 网络设备（NETWORKING）。

1280: 外围设备（PERIPHERAL）。

512: 手机设备（PHONE）。

2048: 玩具设备（TOY）。

1792: 穿戴设备（WEARABLE）。

7936: 未分类（UNCATEGORIZED）。

int rssi: 蓝牙信号强度。

int type: 蓝牙类型。

0: 未知类型（DEVICE_TYPE_UNKNOWN）。

1: 经典 - BR / EDR设备（DEVICE_TYPE_CLASSIC）。

2: 低能耗 - LE-only（DEVICE_TYPE_LE）。

3: 双模式 - BR / EDR / LE（DEVICE_TYPE_DUAL）。
