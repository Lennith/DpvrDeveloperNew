ApiFinishedResult#

Api执行结果。

class ApiFinishedResult {
    var jobId = 0
    var returnCode = 0
    var result: String? = null
    var error: String? = null
}

Property#

int jobId : 该结果对应的 Call 的 jobId 。

int returnCode: Api执行结果，0：成功执行 ，1：任务被取消，2：调用错误。

String result : Api执行结果的Json序列化字符串，对应的是 Api文档中的Result 定义。

String : 当Api调用失败时，用于显示错误原因。
