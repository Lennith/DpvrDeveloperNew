WIFI_DISPLAY_CONNECTION_CHANGED#

Changes in WifiDisplay connection, currently only connection and disconnection.

class WifiDisplayConnectionChanged{
    var connected : Boolean = false
    var deviceInfo : WifiDisplayDeviceInfo? = null
}

Permission#

APP_PERMISSION_NORMAL

Type name#

wifi_display_connection_changed

Property#

Boolean connected: Connect or disconnect, True indicates a new connection, False indicates a disconnection.

WifiDisplayDeviceInfo deviceInfo: Json serialization of the WifiDisplayDeviceInfo list.
