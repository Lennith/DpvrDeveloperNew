GestureSdk 参数说明与注意事项（新版）

1. 文档目的

本文件用于快速说明当前 Assets/GestureSdk 的核心参数与使用注意事项，面向：

  • Unity 集成开发同学
  • 测试/联调同学

2. 关键脚本

  • Assets/GestureSdk/Scripts/CameraManager.cs
  • Assets/GestureSdk/Scenes/GestureTest.cs

3. CameraManager 参数说明

3.1 相机参数

  • cameraWidth / cameraHeight / cameraFps
    • 作用：设置预览分辨率和帧率。
    • 建议：先使用默认值，确认稳定后再调。

3.2 手势参数

  • gesturePreset
    • 作用：识别预设（DEFAULT / PERFORMANCE / ACCURACY）。
  • tickFps
    • 作用：手势处理节拍频率。
    • 建议：5（稳定默认）。
  • numHands
    • 作用：最多识别手数量。
    • 建议：1（稳定默认）。
  • modelComplexity
    • 作用：模型复杂度。
  • inputRotation
    • 作用：输入旋转（建议 CCW_90）。
  • inputScaleMode
    • 作用：输入缩放模式（建议 LETTERBOX）。
  • stabilityFrames
    • 作用：稳定输出需要的连续帧数。
  • hysteresisEnterScale / hysteresisExitScale
    • 作用：进入/退出抖动抑制阈值。
  • fenceMode
    • 作用：同步策略（建议 AUTO）。
  • fenceShortWaitMs
    • 作用：短等待毫秒（建议 0）。
  • classificationMode
    • 作用：分类模式（当前默认 BUILTIN）。
  • emitLandmarks / includeLandmarkInJson
    • 作用：是否输出关键点、是否写入结果 JSON。

3.3 诊断参数

  • enableDiagnosticLogging
    • 作用：打印调试日志。
    • 建议：调试阶段开；上线构建可关。

4. GestureTest 参数说明

  • cameraManager
    • 作用：引用 CameraManager。
  • sphereObject
    • 作用：联动展示球体。
  • cameraImageRect
    • 作用：预览画面的 RectTransform（用于坐标映射）。
  • sceneCamera
    • 作用：场景相机（为空时自动用 Camera.main）。
  • scaleStepFactor
    • 作用：每次放大/缩小步进。
  • maxScaleSteps
    • 作用：最大缩放档位。
  • zDistanceFromCameraImage
    • 作用：球体相对 CameraImage 的深度距离（相机坐标系中沿视线方向移动）。
  • gestureCooldownSeconds
    • 作用：同类手势触发冷却时间。

5. 当前示例手势逻辑

  • V_SIGN
    • 激活球体。
    • 基于手势 roi 更新球体位置（仅在识别到 V_SIGN 时更新一次）。
  • OPEN_PALM
    • 球体放大一档。
  • FIST
    • 球体缩小一档。
  • THUMBS_UP
    • 球体随机变色。

6. 坐标与深度规则（重点）

当前 GestureTest 的位置换算规则：

  1. 取 roi 中心点：
    • centerX = (left + right) / 2
    • centerY = (top + bottom) / 2
  2. X 方向做一次镜像补偿：
    • mappedX = 1 - centerX
  3. Y 方向直接使用当前场景方向：
    • mappedY = centerY
  4. 将 mappedX/mappedY 映射到 cameraImageRect 本地坐标后转世界坐标。
  5. 深度不是直接改世界 z，而是：
    • 把点转换到相机空间
    • 在相机空间中沿 z 方向向相机移动 zDistanceFromCameraImage
    • 再转换回世界坐标

这可以保证“屏幕位置一致 + 深度关系稳定”。

7. 稳定默认值（建议）

  • tickFps = 5
  • numHands = 1
  • inputRotation = CCW_90
  • inputScaleMode = LETTERBOX
  • fenceMode = AUTO
  • fenceShortWaitMs = 0

8. 常见问题与排查

8.1 有画面但没有手势

优先检查：

  • AAR 是否完整在 Assets/Plugins/Android
  • CameraManager 是否已正常初始化
  • 是否有连续手势回调日志

8.2 手在右侧，球在左侧

优先检查：

  • GestureTest 是否仍保留 mappedX = 1 - centerX
  • cameraImageRect 是否绑定到真实显示预览的对象

8.3 上下方向不一致

优先检查：

  • mappedY 当前规则是否与场景预览方向一致
  • 预览材质 _Flip 是否被改动

8.4 球体深度不合理

优先检查：

  • sceneCamera 是否正确
  • zDistanceFromCameraImage 是否过大或过小
不同说明中的 zDistanceFromCameraImage 距离语义与计算表述存在差异；正文按各来源保留，未统一改写算法。
