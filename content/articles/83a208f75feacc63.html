DPVR Video Encryptor User Manual

1. Video Encryption Process

This process applies to the first encryption of new videos. All operations in this process are performed in the video_encryptor\video_encryption folder.

  1. 1Place Video Files:

    Place the video files to be encrypted (must be MP4 format) into the input_video folder.

  2. 2Fill in Device Serial Numbers:

    Enter the serial numbers of the devices required for decryption and playback into the sn.txt file. Each serial number should be on a new line.

    • Manual Addition: Directly edit the sn.txt file.
    • Automatic Generation (only applicable to all-in-one VR devices): Turn on each device and connect it to the computer in sequence, then run the get_sn_tool\sn_get.bat file. This tool will automatically generate an sn.txt file containing the serial numbers. Afterward, copy this generated sn.txt and overwrite the one in video_encryption\sn.txt.
  3. 3Configure Decryption Information:

    Edit the config.ini file and fill in the following decryption parameters:

    • encrypt_effective_date: The expiration date for effective video decryption and playback
      • Format: YYYY/MM/DD
      • Description: Before this date, the video can be decrypted and played normally
      • If empty, defaults to 2099/1/1
    • encrypt_key: The credential for video decryption and playback
      • Format: 16-character string (English letters and numbers only)
      • If empty, defaults to DPVR20222023HHHH
    • vei_key: The key required for updating the video authorization file
      • Format: String (English letters and numbers only)
      • If empty, defaults to dpvr
    Example:
encrypt_effective_date=2025/6/30
encrypt_key=YOUR16CHARSECRET
vei_key=yourveikey
  4. 4Execute Video Encryption:

    Run the encrypt.bat batch file to start the video encryption process.

    After encryption is complete, the following three file formats will be generated in the output_video folder (file names will be the same as the original video):

    • Encrypted video file: .mp4
    • Video verification file: .dpve1
    • Video authorization file: .dpvei

    Note: Please ensure that the disk where the encryption operation is performed has sufficient free space, otherwise video encryption may fail.

  5. 5Import Encrypted Video:

    Copy all encrypted files (encrypted video file, video verification file, video authorization file) to the internal storage of the device requiring decryption and playback. Wear the device to proceed with decryption and playback.

    Note: Please ensure that files with the same name (encrypted video file, video verification file, video authorization file) are placed in the same folder within the device's internal storage.

2. Video Authorization File Update Process

This process is applicable when a video has already been encrypted, and you only need to add new playable device serial numbers or change the video's effective decryption and playback expiration date. All operations in this process are performed in the encrypted_file_update folder.

  1. 1Place Authorization File:

    Place the video authorization file (.dpvei) to be updated into the input_dpvei folder.

  2. 2Update Device Serial Numbers:

    Enter the serial numbers of the devices required for decryption and playback into the sn.txt file. Each serial number should be on a new line.

    • Manual Addition: Directly edit the sn.txt file.
    • Automatic Generation (only applicable to all-in-one VR devices): Turn on each device and connect it to the computer in sequence, then run the get_sn_tool\sn_get.bat file. This tool will automatically generate an sn.txt file containing the serial numbers. Afterward, copy this generated sn.txt and overwrite the one in encrypted_file_update\sn.txt.
  3. 3Configure Update Information:

    Edit the config.ini file and fill in the following parameters:

    • encrypt_effective_date: The new effective decryption and playback expiration date for the video.
      • Format: YYYY/MM/DD
      • Description: Before this date, the video can be decrypted and played normally
      • If empty, defaults to 2099/1/1
    • vei_key: The key for updating the video authorization file
      • Format: String (English letters and numbers only)
      • Important: This key must be consistent with the vei_key set during the initial encryption of this video.
      • If empty, defaults to dpvr
    Example:
encrypt_effective_date=2026/6/30
vei_key=yourveikey
  4. 4Execute Authorization Update:

    Run the update_encrypt.bat batch file to start updating the video authorization file.

    After the update is complete, a video authorization file (.dpvei) with the same name will be output to the output_dpvei folder.

  5. 5Import Authorization File:

    Copy and overwrite the updated video authorization file over the old authorization file on the device to complete the update.
