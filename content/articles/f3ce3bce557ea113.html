StartDpvrVideoPlayer#

Play a specified video file using DpvrVideoPlayer

Permission#

APP_PERMISSION_SYSTEM

Params#

property

type

default

description

mediaPath

String

Address of the file to be played

model

Int

0

Playback mode

isLoop

Boolean

true

Whether to loop playback

startOnPrepared

Int

1

Play directly when default is 1, otherwise it will stop at the first frame

need3Dto2D

Int

1

Whether 3D video shows both eyes or is for the left eye. Customized requirement for 3d video defocus problem, default is 1 for normal display
