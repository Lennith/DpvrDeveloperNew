Unity：绑定设备服务并读取第一条 SN

本页把服务检查、导入、绑定、监听、调用和结果解析串成一个场景组件。完成后，应在目标头显日志中看到 [DMS] SUCCESS sn= 和实际设备序列号。

1. 确认头显已有设备管理服务

准备 Unity Android Build Support、USB 数据线和已授权调试的头显。在 Windows 命令行执行：

adb devices
adb shell pm list packages | findstr com.dpvr.devicemanager

第一条应列出设备且状态为 device；第二条应包含 package:com.dpvr.devicemanager。没有该包时先按官方系统要求检查固件；导入 Unity 包不能安装头显系统服务。下面只有实际连接回调到达后才发起请求。

2. 用 NORMAL 权限开始

systemInfoJobs/GetSerialNo 要求 APP_PERMISSION_NORMAL，没有业务参数，不需要额外授权 Key。本例不添加虚构密钥。以后调用 LAUNCHER、SYSTEM 或 ADMIN 级接口时，再向 DPVR 获取 Key 并在 AndroidManifest 的 application 节点配置：DeviceManagerKey 绑定应用包名和版本；DeviceManagerPlatformKey 绑定包名与渠道固件。

3. 导入官方包，创建一个测试场景

  1. 下载当前 DpvrDeviceManager2.0.unitypackage，通过 Assets → Import Package → Custom Package 全量导入。
  2. 确认项目含 Assets/DpvrDeviceManager/DeviceManagerClientJar.aar 和 Assets/DpvrDeviceManager/LitJson。本例使用包内 LitJson，不需要另装 JSON 库；若项目已有同名库，应避免重复类型。确认 AAR 导入设置适用于 Android。
  3. 在自己的 Scripts 目录创建 DmsSerialNumberExample.cs，粘贴下方完整代码。类名与文件名保持一致。
  4. 在空测试场景创建空对象，挂上该组件。只挂一份，并暂不运行其他会注册 DMS 监听器的组件：每个应用只有一套有效结果、事件监听。

4. 完整组件：等连接，再调用，再匹配结果

结果与事件由两个 AndroidJavaProxy 接收；另外使用当前 AAR 确认存在的连接状态代理。所有代理回调进入队列，由 Update 在 Unity 主线程处理，所以即使结果很早到达，也会在调用返回、保存 jobID 后解析。10 秒提示仅便于定位未返回结果，不是接口超时规则，也不取消任务。

using System;
using System.Collections.Generic;
using LitJson;
using UnityEngine;
using UnityEngine.Scripting;

public sealed class DmsSerialNumberExample : MonoBehaviour
{
    private const string BridgeClass =
        "com.dpvr.devicemanagerclientjar.DeviceManagerBindMan";
    private readonly Queue<Action> mainThread = new Queue<Action>();
    private readonly object queueLock = new object();
    private AndroidJavaObject bridge;
    private ResultProxy resultProxy;
    private EventProxy eventProxy;
    private StateProxy stateProxy;
    private volatile bool closing;
    private bool bindRequested;
    private bool connected;
    private int? pendingJob;
    private float pendingSince;

    [Preserve]
    public sealed class Accepted
    {
        public int jobID;
        public string errorDescription;
    }

    [Preserve]
    public sealed class Completed
    {
        public int jobId;
        public int returnCode;
        public string result;
        public string error;
    }

    [Preserve]
    public sealed class SerialNumberResult
    {
        public string sn;
    }

    private void Start()
    {
#if UNITY_ANDROID && !UNITY_EDITOR
        try
        {
            using (var player = new AndroidJavaClass("com.unity3d.player.UnityPlayer"))
            using (var activity = player.GetStatic<AndroidJavaObject>("currentActivity"))
                bridge = new AndroidJavaObject(BridgeClass, activity);

            resultProxy = new ResultProxy((id, json) =>
                Post(() => HandleResult(id, json)));
            eventProxy = new EventProxy((type, json) =>
                Post(() => Debug.Log("[DMS] Event " + type + ": " + json)));
            stateProxy = new StateProxy(state => Post(() => HandleState(state)));

            bridge.Call("SetDeviceManagerResultListener", resultProxy);
            bridge.Call("SetDeviceManagerEventListener", eventProxy);
            bridge.Call("SetServiceStateListener", stateProxy);
            bridge.Call("SetBind");
            bindRequested = true;
            Debug.Log("[DMS] Binding requested; waiting for service connection.");
        }
        catch (Exception e)
        {
            Debug.LogError("[DMS] Setup failed: " + e);
        }
#else
        Debug.LogWarning("[DMS] Build and run on an Android headset; Editor is not supported.");
#endif
    }

    private void Post(Action action)
    {
        lock (queueLock)
        {
            if (!closing) mainThread.Enqueue(action);
        }
    }

    private void Update()
    {
        while (true)
        {
            Action action;
            lock (queueLock)
            {
                if (mainThread.Count == 0) break;
                action = mainThread.Dequeue();
            }
            try { action(); }
            catch (Exception e) { Debug.LogError("[DMS] Callback failed: " + e); }
        }
        if (pendingJob.HasValue && Time.realtimeSinceStartup - pendingSince > 10f)
        {
            Debug.LogWarning("[DMS] Still waiting for job " + pendingJob.Value +
                ". Check listeners and device logs; this is not a cancellation.");
            pendingSince = float.PositiveInfinity;
        }
    }

    private void HandleState(bool state)
    {
        connected = state;
        Debug.Log("[DMS] Connected=" + state);
        if (state && !pendingJob.HasValue) RequestSerialNumber();
        if (!state)
        {
            pendingJob = null;
            Debug.LogWarning("[DMS] Connection lost. An accepted job may still exist on the device.");
        }
    }

    public void RequestSerialNumber()
    {
        if (!connected || bridge == null || pendingJob.HasValue) return;
        try
        {
            string json = bridge.Call<string>("CallInterface",
                "systemInfoJobs", "GetSerialNo", null, null);
            if (string.IsNullOrEmpty(json))
            {
                Debug.LogError("[DMS] Empty acceptance response; check service connection.");
                return;
            }
            Accepted accepted = JsonMapper.ToObject<Accepted>(json);
            if (accepted.jobID < 0)
            {
                Debug.LogError("[DMS] Rejected: " + accepted.errorDescription);
                return;
            }
            pendingJob = accepted.jobID;
            pendingSince = Time.realtimeSinceStartup;
            Debug.Log("[DMS] Accepted jobID=" + accepted.jobID);
        }
        catch (Exception e) { Debug.LogError("[DMS] Submission failed: " + e); }
    }

    private void HandleResult(int jobId, string json)
    {
        Debug.Log("[DMS] Result jobId=" + jobId + ": " + json);
        if (!pendingJob.HasValue || jobId != pendingJob.Value) return;
        try
        {
            Completed completed = JsonMapper.ToObject<Completed>(json);
            if (completed.returnCode != 0)
            {
                Debug.LogError("[DMS] Completion failed: code=" +
                    completed.returnCode + " error=" + completed.error);
                return;
            }
            SerialNumberResult value =
                JsonMapper.ToObject<SerialNumberResult>(completed.result);
            if (value == null || string.IsNullOrEmpty(value.sn))
                Debug.LogError("[DMS] Completed without a serial number: " + json);
            else
                Debug.Log("[DMS] SUCCESS sn=" + value.sn);
        }
        finally { pendingJob = null; }
    }

    private void OnDestroy()
    {
        closing = true;
        lock (queueLock) mainThread.Clear();
        if (bridge == null) return;
        try { if (bindRequested) bridge.Call("UnBind"); }
        catch (Exception e) { Debug.LogWarning("[DMS] Unbind: " + e.Message); }
        finally { bridge.Dispose(); bridge = null; }
    }

    [Preserve]
    private sealed class ResultProxy : AndroidJavaProxy
    {
        private readonly Action<int, string> handler;
        public ResultProxy(Action<int, string> handler)
            : base(BridgeClass + "$OnDeviceManagerResult") { this.handler = handler; }
        [Preserve]
        public void OnDeviceManager(int jobId, string json) { handler(jobId, json); }
    }

    [Preserve]
    private sealed class EventProxy : AndroidJavaProxy
    {
        private readonly Action<string, string> handler;
        public EventProxy(Action<string, string> handler)
            : base(BridgeClass + "$OnDeviceManagerEventResult") { this.handler = handler; }
        [Preserve]
        public void OnDeviceManagerEvent(string type, string json) { handler(type, json); }
    }

    [Preserve]
    private sealed class StateProxy : AndroidJavaProxy
    {
        private readonly Action<bool> handler;
        public StateProxy(Action<bool> handler)
            : base(BridgeClass + "$ServiceConnectState") { this.handler = handler; }
        [Preserve]
        public void onStateChange(bool connected) { handler(connected); }
    }
}

5. 构建到 Android，核对三个阶段

  1. 把当前测试场景加入构建列表，目标平台选择 Android，使用适合目标设备的项目配置，执行 Build And Run。本例不能在 Unity 编辑器中调用 Android 服务。
  2. 在电脑观察头显日志：
adb logcat -s Unity

依次应看到 Connected=True、Accepted jobID=...，以及同一任务完成后的 SUCCESS sn=...。只有最后一条表示业务完成；收到 jobID 本身只是受理。返回 JSON 中外层 result 是业务 JSON 字符串，代码会再解析一次以取得 sn。

6. 按停留阶段排查

  • 编译时找不到 LitJson：检查包是否完整导入，以及自建 asmdef 是否能引用包含 LitJson 的程序集。示例放普通 Scripts 目录时不要遗漏包内代码。
  • 找不到 Java 桥接类：检查 AAR 的 Android 导入设置、构建产物及是否在真机运行。
  • 一直没有 Connected=True：核对系统服务和绑定日志；不要靠固定延迟假装已连接。
  • Rejected：读取 errorDescription；本例是 NORMAL，先核对目标 API、设备服务和请求，不要盲目添加高权限 Key。
  • Accepted 后没有结果：检查监听器是否被其他组件覆盖、测试对象是否被销毁，以及日志里的 jobID 是否一致。10 秒日志不等于任务取消。
  • Completion failed：保留实际 returnCode 和 error。原文对非零码的表述不完全一致，本例只把 0 作为成功，不硬编码其他含义。
  • 断线或离开场景：组件释放本地绑定，不承诺撤销已被设备受理的任务。本例只做单项读取，不作为并行任务管理框架。

为得到一个完整组件，本页补齐 currentActivity、所有字段、代理类和 JSON 类型，修正原片段的未定义变量与拼写；加入主线程队列、jobID 匹配、错误日志与解绑，未原样拼接含错误的片段。示例已做来源和结构审读，未使用 Unity 编译、未打包运行或做头显实测；包内桥接版本变化时应重新核对。
