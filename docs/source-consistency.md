## 保留的真实边界

DMS 是头显内 AIDL SDK，不是 PC GUI。NORMAL 以上权限需要对应授权，提交成功不等于执行完成，结果/事件 listener 各仅一个；型号和版本按逐 API 原文。

RDC 是 TCP 协议/C# 开发库，需要头显服务。发现依赖同广播域；HTTP 文件源需另建；约 ±1 秒的同步不是帧同步；AIDL 和 DMS 透传监听不可同时绑定。GO 与 GO2 都保留，GO2 不替代所有 GO 型号。

标准 Miracast 与 DPVR 无线投屏不同；StartMiracast 的 RTSP8554/stream1 与 wifidisplayJobs 分开说明。加密三件套同名同目录；GUI 加密与 CLI 更新授权的范围不混同，GUI 2.0.0 手册不是待删除的“旧加密 V2”。

PlaybackJSON 由系统播放器启动时读取，不负责头显开机启动播放器。distance 中文 -120…200 与英文 120…200 的矛盾保留并标未确认。TF 的 OTA_PACKAGE 仅复制，APK/ZIP 可先暂存，不支持 P1 Max。

UnityPlayer 在自己的 Unity 场景中播放，保留 Multithreaded Rendering、SinglePass/OpenXR Multi-pass、IL2CPP ARM64、Plane/RawImage 材质条件。Gesture 限 P1 Pro 4K Camera，要求相机权限/AAR/真机；V_SIGN/Vsign 一次定位，不等于连续三维手追踪。GO 动画文件名和手势距离公式等原文差异保持显式说明，不虚构设备验证结果。
