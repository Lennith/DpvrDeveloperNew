PC utility

AIO GO

Inspect headset information, install applications and perform maintenance from a PC.

Supported headsets: P2 · P1 Ultra 4K · P1 Pro 4K · P1 Pro · P1

AIO GO and AIO GO 2 support different model sets. Do not replace one solely because of its name; understand the effects of maintenance operations such as factory reset.

Get started →Download Windows installer ↗

Before you begin

  • Prepare a Windows 10 PC, a supported headset and a USB data cable, as specified in the official guide.
  • Download and extract the official package.

Follow the workflow

01

Install the tool

Run Setup.exe from the package to install AIO GO.

02

Connect over USB

Power on the headset, connect it to the PC and check that the tool recognizes it.

03

Check device information

Check the serial number and firmware version to confirm the selected device.

04

Choose the required operation

Select app installation, file management, screenshots, recording or logs. Use device-matched files for firmware maintenance.

When something goes wrong

  • Use the USB file-access guide when storage is unavailable; it is not an ADB authorization guide.
  • Available documentation does not establish every driver, wireless or firmware compatibility requirement.
  • For unrecognized custom device names, follow the Device.config instructions in the official PDF.
