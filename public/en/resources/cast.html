Casting guide and receiver app

Screen Cast

Display the live headset screen on a compatible receiver using the appropriate casting method.

Supported headsets: P1 Max · P2 · P1 Ultra 4K · P1 Pro 4K · P1 Pro

These are alternative routes, not consecutive steps. This guide does not establish audio, latency or multi-receiver behavior.

Get started →Download receiver app ↗

Before you begin

  • Choose between Miracast and DPVR wireless casting based on the receiver.
  • DPVR wireless casting requires an Android 4.4+ TV or tablet, the receiver app and the same Wi-Fi network.

Follow the workflow

01

Open casting settings

Open Quick Settings on the headset and select casting.

Read: Open casting settings →
02

Choose the receiver method

Choose Android casting for a Miracast receiver, or wireless casting for the DPVR receiver app.

Read: Choose the receiver method →
03

Complete the selected branch

Miracast: enable system casting and select the receiver. DPVR wireless: install and open TV_ScreenPlayer.apk on the receiver, use the same Wi-Fi and start casting.

Read: Complete the selected branch →

When something goes wrong

  • For wireless casting, check that the receiver app is open and both devices use the same Wi-Fi.
  • Miracast receivers must support the protocol; Android TV alone does not establish compatibility.
