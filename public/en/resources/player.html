Unity plug-in

Unity Player Plug-in

Display video in your own Unity application with playback, pause and progress controls.

Supported headsets: P1 Max · P2 · P1 Ultra 4K · P1 Pro 4K · P1 Pro

This embeds playback in your app; it is not a system-player configuration or casting receiver. No Unity or headset execution test is claimed.

Get started →Download Unity player plugin ↗

Before you begin

  • Disable Multithreaded Rendering.
  • Do not enable Use SinglePass with DPVR Unity SDK 0.8.1; use Multi-pass with OpenXR.
  • Check IL2CPP and 64-bit architecture settings against the guide.

Follow the workflow

01

Import the current package

Extract PlayerPlugin.zip and import its current file, Player20260904.unitypackage.

Read: Import the current package →
02

Start with automatic playback

Use the automatic example, enable AutoPlay, set MediaUrl and assign display targets to VOuts.

Read: Start with automatic playback →
03

Match targets and materials

Use DPVR/PlainTextureYUV for a Plane and DPVR/YUVTexture for a RawImage, with the corresponding materials.

Read: Match targets and materials →
04

Use scripted control when needed

Disable automatic playback and reference IjkPlayer, the media URI and targets. Set VOuts before calling Play and handle the prepared callback.

Read: Use scripted control when needed →
05

Connect playback state

Use Duration and Current for state, and Pause, Resume and Seek for control. The short guide does not establish the time units.

Read: Connect playback state →

When something goes wrong

  • If no picture appears, check rendering mode, targets, materials and the media URI.
  • Decryption is listed as a feature, but the guide does not provide a complete V3 key and URI integration example.
