Unity Gesture Plug-in

Integrate camera preview and gesture callbacks on the supported headset, then map results to scene interactions.

Supported headsets: P1 Pro 4K Camera

The sample demonstrates gesture classification and sphere interaction, not a complete 3D hand-skeleton system. The current bundled beginner guide explicitly requires disabling multithreaded rendering.

Get started →Download Unity gesture kit ↗

Before you begin

  • Use the listed P1 Pro 4K Camera model; the Camera qualification matters.
  • Install Unity Android Build Support, switch to Android and enable USB debugging on the headset.
  • Grant camera permission and disable Multithreaded Rendering.

Follow the workflow

01

Import the complete plug-in

Import Gesture.unitypackage from GestureDemoPlugin.zip. The current AAR files are in Assets/Plugins/Android, unlike the old manual path.

Read: Import the complete plug-in →
02

Run the sample on a device

Open Assets/GestureSdk/Scenes/SampleScene.unity and Build And Run on the headset. The editor cannot replace the Android Camera/AAR pipeline.

Read: Run the sample on a device →
03

Check preview and four interactions

Verify the preview: V_SIGN activates and positions the sphere once; OPEN_PALM enlarges it, FIST shrinks it and THUMBS_UP changes its color.

Read: Check preview and four interactions →
04

Integrate your own scene

Assign the RawImage to CameraManager. Bind GestureTest to the camera manager, target object, preview RectTransform and rendering camera.

Read: Integrate your own scene →
05

Keep stable settings before tuning

Start with tickFps=5, numHands=1, CCW_90, LETTERBOX and AUTO. Apply horizontal mirroring and compute depth in camera space.

Read: Keep stable settings before tuning →

When something goes wrong

  • No preview: check the device, AAR dependencies, camera permission and multithreaded-rendering setting.
  • Preview without gestures: check initialization, parameters and continuous seq logs.
  • Incorrect position: check the preview reference, mirroring, rendering camera and depth offset.
