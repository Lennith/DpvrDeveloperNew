PC utility

AIO GO 2

A portable Windows utility for mirroring, recording, transferring files and installing apps.

Supported headsets: P1 Max · P2

The filename update.zip triggers firmware-related behavior and should not be uploaded as ordinary content. Verify firmware compatibility separately.

Who it is for
Device operators and demo teams
Where it runs
Portable Windows tool with ADB / Scrcpy; USB for the first connection
Get started →Download portable Windows tool ↗

Before you begin

  • Use a P1 Max or P2 with a Windows PC and a USB data connection.
  • ADB and Scrcpy are bundled; separate installation is not a documented prerequisite.

Follow the workflow

01

Extract and run

Download and extract the official package, then double-click to run without installation.

Read: Extract and run →
02

Connect and identify the headset

Power on the headset, connect it over USB and wait for model, battery, serial and system information.

Read: Connect and identify the headset →
03

View or record the screen

Choose mirroring, recording, screenshots or log capture. Documentation does not establish all output locations.

Read: View or record the screen →
04

Transfer content or install apps

Transfer content through the file area. The APK area installs apps after transfer, so verify the selected file first.

Read: Transfer content or install apps →

When something goes wrong

  • If no device is detected, check headset power and the USB data connection.
  • A wireless switch is visible, but available sources do not provide a complete pairing procedure.
