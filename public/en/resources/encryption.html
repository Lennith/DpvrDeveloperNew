Video Encryption and Authorization

Prepare MP4 content on a PC with headset serial-number and expiry-date authorization.

Supported headsets: P1 Max · P2 · P1 Ultra 4K · P1 Pro 4K · P1 Pro

Encryption V3 and GUI version 2.0.0 describe different components. GUI and CLI constraints and defaults differ. Sources do not establish serial-number enforcement on every platform.

Get started →Download encryption tools ↗

Before you begin

  • Prepare MP4 files, headset serial numbers, expiry dates and sufficient disk space.
  • The GUI requires Windows 10/11 x64. Retain local keys, the admin password and management data.

Follow the workflow

01

Choose GUI or batch processing

Use the GUI for day-to-day content and device lists, or the CLI for configuration-driven automation.

Read: Choose GUI or batch processing →
02

Prepare keys and devices

In the GUI, configure keys and the admin password before adding serial numbers. For the CLI, prepare sn.txt and config.ini as documented.

Read: Prepare keys and devices →
03

Set authorization and encrypt

Select the MP4, expiry date and devices in the GUI, or put MP4 files in input_video and run encrypt.bat for the CLI.

Read: Set authorization and encrypt →
04

Deploy the complete file set

Place matching .mp4, .dpve1 and .dpvei files in the same internal-storage directory on the target headset and verify playback with a supported player.

Read: Deploy the complete file set →
05

Update authorization when needed

The CLI authorization workflow updates .dpvei using the original vei_key. Replace the old authorization file. GUI Save & Encrypt re-encrypts and overwrites output.

Read: Update authorization when needed →

When something goes wrong

  • Check MP4 format, free space, duplicate output names and selected serial numbers.
  • Authorization updates require the original VEI_KEY. Saved GUI keys cannot be changed or recovered.
