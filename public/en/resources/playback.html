Headset configuration file

System Player Configuration

Use JSON to configure the startup video, projection format, headset-wear behavior and player controls.

Supported headsets: P1 Max · P2 · P1 Ultra 4K · P1 Pro 4K · P1 Pro

The web and downloadable examples use different valid lockView values, not a single mandatory default. This file does not generate video authorization.

Get started →Download JSON example ↗

Before you begin

  • Deploy the video to the headset and confirm its absolute path.
  • Identify its flat, panoramic and stereoscopic layout.

Follow the workflow

01

Set the path and video format

Set videoPath in AutoPlayDisposition.json and choose videoModel to match the actual layout.

Read: Set the path and video format →
02

Choose playback behavior

Configure autoplay, display-on or headset-removal behavior, restart or resume, and visible controls. lockView selects head-following or world-fixed placement.

Read: Choose playback behavior →
03

Place the configuration

Create AutoVideoPlay at the root of shared storage and place the JSON file inside.

Read: Place the configuration →
04

Start the player and verify

The player reads the file at startup. Check the path, projection, headset-removal behavior and controls.

Read: Start the player and verify →

When something goes wrong

  • If playback does not start, check the filename, AutoVideoPlay location and absolute video path.
  • distance only applies to flat modes 0, 1 and 4. Published range descriptions differ by language and need device verification.
