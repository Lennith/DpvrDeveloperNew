Remote protocol and library

RDC Remote Device Control

Build a controller for multiple headsets on a local network and exchange messages with headset apps.

Supported headsets: P1 Max · P2 · P1 Ultra 4K · P1 Pro 4K · P1 Pro

RDC sends content manifests and does not proxy files. Downloads require a separate HTTP service. Library defaults are not performance guarantees.

Who it is for
Fleet-control software developers
Where it runs
PC or LAN controller + headset RDC service; TCP protocol / C# library
Get started →Download remote control kit ↗
Your controller⟷ TCP / LAN ⟷Multiple DPVR headsets

Before you begin

  • Confirm the RDC service and any additional services required by the selected features.
  • Prepare a LAN; automatic discovery also requires the same broadcast domain and permitted broadcasts.

Follow the workflow

01

Choose a controller route

Use the .NET 7 Win64 library where appropriate, or implement the TCP protocol for other platforms or direct protocol access.

Read: Choose a controller route →
02

Check headset services

Verify RDC, the player and any required startup service. Installing a PC library does not add missing headset services.

Read: Check headset services →
03

Configure the connection

Set the server IP and port on the headset, or use automatic discovery. Automatic discovery overrides the manually entered address.

Read: Configure the connection →
04

Start the server and identify clients

Register connection and message callbacks, start listening, and select a client after it connects and reports its serial number.

Read: Start the server and identify clients →
05

Verify the required feature

Check one device before scaling out. Content distribution additionally requires HTTP/HTTPS file URLs accessible to each headset.

Read: Verify the required feature →

When something goes wrong

  • If discovery fails, check the broadcast domain, router settings and headset configuration.
  • A sent command does not confirm playback, casting or download completion; inspect the relevant status.
