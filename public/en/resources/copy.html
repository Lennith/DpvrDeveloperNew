On-device deployment app

TF Card Deployment Tool

Read a task list on the headset to install apps, unpack resources and copy files.

Supported headsets: P2 · P1 Ultra 4K · P1 Pro 4K · P1 Pro

This is not a TF-card cloning tool. OTA_PACKAGE copies an update package but does not start a firmware upgrade.

Get started →Download headset app & config ↗

Before you begin

  • Install CopyTool.apk on a supported headset.
  • Prepare a TF card, the referenced source files and sufficient headset storage.

Follow the workflow

01

Define the task list

Create a copy_config.json array using APK, ZIP_UNPACK, FILE, OBB, LANGUAGE_PACKAGE or OTA_PACKAGE as required.

Read: Define the task list →
02

Set sources and destinations

Set source, dist and optional name. ${EXT_SD} means the TF card root; APK tasks ignore dist.

Read: Set sources and destinations →
03

Place the configuration and content

Put the configuration at the TF card root and place each source file at its configured path.

Read: Place the configuration and content →
04

Run and inspect the tasks

Insert the card and open the tool to load and execute tasks. Inspect progress, success and failure counts, logs and the post queue.

Read: Run and inspect the tasks →
05

Clear temporary data as needed

APK and ZIP files from the card are first copied to local temporary storage. Clear the cache from the post-queue area when appropriate.

Read: Clear temporary data as needed →

When something goes wrong

  • Check ${EXT_SD} and the actual card layout when a source is missing.
  • For installation or extraction failures, inspect logs and local free space as well as the destination.
