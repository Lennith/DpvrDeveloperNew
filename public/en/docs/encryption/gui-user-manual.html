DPVR Video Encryptor · User Guide

Local video encryption & device authorization tool — Key setup → Device SN management → Video add & encrypt → Deploy to VR headsets
Version 2.0.0 Windows 10/11 x64 中文 / English Runs locally · No internet required

Contents

  1. Installation & Launch
  2. First-run Setup (Language / Keys / Admin Password)
  3. Device Management (Groups & SN)
  4. Video Management (Add / Encrypt / Edit / Delete)

1. Installation & Launch

1
Double-click to run the installer DPVR视频加密工具-Setup-2.0.0.exe.
2
Follow the wizard to complete the installation; you can tick Run DPVR Video Encryptor Platform to launch it directly.
3
Launch (either way): ① double-click the desktop / Start-menu shortcut "DPVR Video Encryptor Platform"; ② double-click EncryptedVideoTool.exe in the installation directory.
Tip: the app is a local standalone tool — all data (keys, devices, videos) stays on this machine and works fully offline.

2. First-run Setup (Language / Keys / Admin Password)

On first launch the app forces you into the Settings page; complete language confirmation, key configuration and the admin password before using other features.

2.1 Language Settings

1
The default follows your current system/browser language: Chinese → 中文, otherwise → English.
2
You can switch 中文 / English anytime from the language card at the top of the Settings page; changes apply immediately.

2.2 Key Configuration

Key Spec Purpose Example
Encryption key encrypt_key 16 characters, English letters and digits only Credential for video encryption and playback decryption A1b2C3d4E5f6G7h8
Authorization key VEI_KEY 12 characters, English letters and digits only Credential for authorization file updates X9y8Z7w6V5u4
1
Type the keys manually, or click Random to generate a compliant value (a spec example is shown next to each input).
2
Set the admin password (at least 6 characters) and confirm it — used later to view the keys on the Settings page.
3
Click Save Keys; after "Keys saved" the app enters Device Management automatically.
Important: keys are immutable once saved — keep them safe. Losing the keys means encrypted videos can no longer be decrypted or re-authorized.
Note: do not use the engine built-in defaults. After saving, keys are masked on the Settings page; enter the correct admin password and click "View Keys" to reveal them.

3. Device Management (Groups & SN)

Device management maintains the serial number (SN) list of your VR headsets — the data source for video binding and authorization. Left: the group tree (the "All Devices" root shows the total SN count, groups show count badges); right: the SN table (SN, group, added time).

3.1 Device Group Management

  • New group: click "New Group" and enter a name (required, must be unique).
  • Edit group: rename a group.
  • Delete group: deleted after confirmation; its SNs are kept under the "All Devices" root — nothing is lost.

3.2 Add SN

Single add: click Add SN → enter the SN and pick the group ("All Devices" means no group) → OK.

  • SN format: 2–120 characters, letters, digits and . _ : - only; spaces are not allowed.
  • SNs must be unique within the same group.

Batch add: click Batch Add → paste text or drop a txt file (one SN per line) → pick the group → import. Every line is validated and de-duplicated, with a summary "N succeeded, M duplicates, K invalid".

3.3 Edit / Delete SN

  • Edit: the row "Edit" button changes the SN value and its group.
  • Delete: tick one or more SNs and click "Batch Delete" (or delete a single row), then confirm. Deleting a bound SN unbinds it from all videos.

3.4 Export SN

Click Export SN: with "All Devices" selected it exports every SN; with a group selected it exports only that group, as a txt file (one per line).

4. Video Management (Add / Encrypt / Edit / Delete)

The Video Management page lists local videos and supports adding, encrypting, editing, deleting and filtering.

4.1 List Columns

Column Description
Video file name The source file name (without extension) used when adding
Valid until Authorization expiry date; shown in red when expired
Encrypt status Not encrypted (gray) / Encrypting (blue) / Success (green) / Failed (red)
Encrypted at Completion time; - when not encrypted
Devices Number of bound devices; click "Details" to expand the bound SN list

4.2 Add Video & Encrypt (Single)

1
Click Add Video and choose "Single"; then select or drop an MP4 video file (MP4 only).
2
Set the valid-until date with the calendar picker — defaults to today + 5 years, and cannot be earlier than today.
3
Bind device SNs (required): tick devices in the tree-select; ticking a group selects the whole group, with a live count of selected devices.
4
Click Encrypt — the video is saved and encryption starts automatically; the progress dialog shows a bar and an integer percentage (the overlay cannot be dismissed by clicking).
5
When finished, the status becomes "Success" with the encryption time; output is saved to the EncryptVideo folder in the installation directory.
Screenshot placeholder: single-add dialog & encryption progress dialog
Note: if a file with the same name already exists in EncryptVideo (or in the list), the video cannot be added — delete or rename the source file first.

4.3 Batch Add

1
Click Add Video → "Batch", then drop multiple video files into the window.
2
In the common settings area, set the shared valid-until date and bound device SNs (required) — applied to every video in the batch.
3
Review the preview list and click Encrypt; videos are encrypted one by one automatically, and non-MP4 files are filtered with a notice.

4.4 Filter & Search

  • Filter by device group: the filter defaults to "All Devices" (all videos); picking a group shows only videos bound to SNs of that group.
  • Search by file name: type a keyword in the search box to filter the list instantly.

4.5 Edit Video (Save & Encrypt)

1
Click the row "Edit" button to change the valid-until date and bound device SNs.
2
Click Save & Encrypt: changes are saved and re-encryption starts automatically with the new date and device list.
Note: re-encrypting overwrites the previous encrypted output.

4.6 Delete Videos

  • Single delete: row "Delete" → confirmation with a red "irreversible" warning.
  • Batch delete: tick multiple videos (encrypting ones cannot be ticked) → "Batch Delete" → confirm.
  • Deleting also removes the local records and the matching files in the EncryptVideo folder.

4.7 Open Output Folder

Click "Open Folder" to open the EncryptVideo folder in File Explorer.

5. Encrypted Output & Playback

After a successful encryption, three kinds of files are generated in <install dir>\EncryptVideo:

File Description
*.dpve1 + *.mp4 Encrypted video data and container file
*.dpvei Authorization file (contains the expiry date and bound device SNs)
  • V3 encryption supports MP4-container sources only.
  • Encrypted videos can only be played by Dpvr VideoPlayer.
  • Authorization: expiry-date authorization (video valid-until; unplayable when expired) + device SN authentication (only bound SNs can play).

6. Notes & Common Messages

Scenario What to do
Message "Please configure keys in Settings first" Keys not configured — finish key setup in "Settings" before encrypting
Message "Only MP4 video files are supported" The source is not MP4-container; convert it to MP4 first
Message "A file with the same name already exists in EncryptVideo" Same-name output exists — delete the old video or rename the source file and retry
Message "Valid-until date cannot be earlier than today" Pick today or a later date
Forgot the admin password Key plaintext cannot be revealed; always remember the admin password and the keys
OS change / reinstallation Local data (keys, devices, list) does not migrate automatically — plan backups in advance
Data locations Config & list data live in the local user-data directory; encrypted output lives in EncryptVideo under the install directory
Security reminder: the encryption key and authorization key are the only credentials for decryption — immutable and unrecoverable once set. Keep them safe.
