VideoEncryptor¶

This tool is designed to help developers batch encrypt video files using the Dpvr V3 encryption method. It offers better performance compared to traditional AES stream encryption.

Note

V3-encrypted videos can only be decrypted and played using the Dpvr VideoPlayer and only support MP4 container format.

If you need to encrypt non-MP4 video files, you can use the DPVR Video Encryption Tool V1 instead.

Compared with the V1 version, V3 video encryption consumes fewer resources during playback, providing performance equivalent to the original video.

Warning

V3 authorization files only support V3-encrypted videos, and V1 authorization files only support V1-encrypted videos. The two encryption methods are completely different at the implementation level. When played on non-standalone devices, both methods only validate authorization time and do not verify the device.

Features¶

VideoEncryptor is a console application that provides the following three functions:

  1. Encrypt MP4 videos in the specified directory, generating encrypted video files (.dpve1, .mp4) and corresponding authorization files (.dpvei).

  2. Update V3 authorization files (.dpvei) in the specified directory to support new device serial numbers and authorization dates.

  3. Update Dpvr V1 authorization files (.dat) in the specified directory and generate new V1-encrypted authorization files.

Click here to download the VideoEncryptor tool.

Authorization methods include:

  1. Authorization by device serial number (SN).

  2. Authorization by date.

Usage Process:

  1. Use DpvrEncryptorUpdate.exe to encrypt MP4 video files in the specified path, generating .dpve1/.mp4 and .dpvei files.

  2. Use DpvrVideoPlayer to play the video using the .dpvei1 file as the entry point.

Command Line Arguments¶

-e <Boolean> or –encrypt_dpvr_v3 <Boolean>

Choose the working mode: - false: Update authorization files - true: Encrypt video files (default: false)

-b <String> or –encrypt_key <String>

16-character alphanumeric string. Required for V3 encryption. Acts as the decryption key during playback. Default is DPVR20222023HHHH.

-c <Date> or –encrypt_effective_date <Date>

Authorization effective date in the format YYYY/MM/DD. - For encryption: defaults to 2099/01/01. - For updates: defaults to the original authorization date.

-i <String> or –input_dir <String>

Input folder path. - In encryption mode: path to MP4 files. - In update mode: path to authorization files.

-o <String> or –output_dir <String>

Output folder path. - In encryption mode: output path for encrypted videos and authorization files. - In update mode: output path for updated authorization files.

-d <String> or –device_list <String>

Path to device list file. One serial number per line in a .txt file.

-y <String> or –output_vei_key <String>

Output VEI_KEY. Only valid in V3 encryption mode. Used for future updates. Defaults to dpvr during encryption. If updating, it retains the previous VEI_KEY.

-k <String> or –input_vei_key <String>

Input VEI_KEY. Used when updating V3 authorization files. Must match the VEI_KEY used during encryption.

-t <String> or –update_type <String>

Optional values: dat or vei. Only effective in update mode. Specifies the type of updated authorization file. Defaults to vei.

-h or –help

Displays help information for all command-line options.

Usage Examples¶

Encryption¶

DpvrEncryptorUpdate.exe --encrypt_dpvr_v3 true --input_dir d:\test --output_dir d:\testout
--device_list d:\devicelist.txt --output_vei_key test

Encrypts all MP4 files in the specified folder using V3 encryption, and outputs to the target folder.

Authorization File Update¶

V3 Authorization Update:

DpvrEncryptorUpdate.exe --input_dir d:\test --output_dir d:\testout --update_type vei
--device_list d:\devicelist.txt --input_vei_key test --output_vei_key test

Updates all authorization files in the folder (including V1 and V3). Outputs new V3 authorization files to the target folder.

V1 Authorization Update:

DpvrEncryptorUpdate.exe --input_dir d:\test --output_dir d:\testout --update_type dat
--device_list d:\devicelist.txt

Updates all V1 (.dat) authorization files and generates updated V1 authorization files in the output path.
