ApkEncryptor¶

This tool is designed to help developers quickly complete the development of application authentication functionality. It provides an application authorization file generation tool with the following two features:

  1. Generate authorization files (.dpaei) through APK files and a list of authorized devices.

  2. Update existing authorization files (.dpaei).

Click here to download the authorization file generation tool.

The authentication methods covered by the authorization file include:

  1. Authentication based on device serial number.

  2. Authorization based on the authorization date.

Usage Process¶

  1. Use ApkEncryptor to generate the authorization file and record the Encryptor_Key entered during the generation.

  2. Place the authorization file in the specified location on the device as the authorization credential for the device.

  3. Call the authentication interface of DeviceManager, pass in the generated authorization file and Encryptor_Key for verification.

  4. After successful authentication, the application can be used normally.

  5. When updating an existing .dpaei authorization file, you need to use the Encryptor_Key that was used to generate the authorization file for verification.

Attention

The application will not be checked for authentication by the system if the DeviceManager authentication interface is not called within the application.

Encryption Tool Usage¶

Authorization Generation:

DpvrApkEncryptor.exe -m encrypt -i <input_apks_dir> -o <output_dpaei_dir> -k <encryptor_key> -d <device_list_file> -c <effective_date>

-m: encrypt: Generate authorization file.

-i: Input APK file directory.

-o: Output authorization file directory.

-k: Encryptor_Key entered when generating the authorization file.

-d: Authorized device list file, with all authorized devices placed in one file. The file format is txt, with one device serial number per line.

-c: Authorization file validity period in the form: 2021/01/01.

Authorization Update:

DpvrApkEncryptor.exe -m update -i <input_dpaei_dir> -o <output_dpaei_file> -k <encryptor_key> -d <device_list_file>

-m: update: Update authorization file.

-i: Input authorization file dpaei directory.

-o: Output authorization file directory.

-d: Authorized device list file, with all authorized devices placed in one file. The file format is txt, with one device serial number per line.

-c: Authorization file validity period in the form: 2021/01/01.

Device-Side Authentication¶

Place the generated authorization file in the specified location on the device as the authorization credential for the device. Call the packageJobs/CheckApplicationAuthority interface of DeviceManager for authentication, returning True upon success. For details, please refer to the DeviceManager documentation.

Example Call (Kotlin):

class ParamsAuthority{
    // Whether to automatically kill the application. It only auto-closes if the caller and the checked package name are the same. Default is false.
    var autoKill: Boolean = false
    // The package name of the application to be checked for authorization. Default is the caller's package name.
    var packageName: String? = null
    // Encryptor_key used during encryption
    var key: String = "dpvr"
    // Path to the authorization file, default is /sdcard/applicationAuthority/<packageName>.dpaei
    var keyFilePath: String? = null
}

fun testAuthority(){
    val params = ParamsAuthority().apply {
        packageName = "com.dpvr.qatool"
        keyFilePath = "/sdcard/applicationAuthority/com_dpvr_qatool.dpaei"
        key = "dpvr"
    }
    val cat = "packageJobs"
    val type = "CheckApplicationAuthority"
    call(cat, type, params, null, object : ResultCallback {
        override fun onResult(result: BinderEntities.ApiFinishedResult) {
            Log.i(TAG, "result")
        }
    })
}
