Client Usage¶

The existing RDC client service includes the following remote control functions:

  1. Video Control: Includes playing videos, closing videos, pausing/resuming playback, and volume settings.

  2. Application Control: Starting and closing applications.

  3. Key Blocking: Blocking and unblocking physical buttons and the touchpad.

System Requirements¶

First, ensure the RDC service is installed on the system. You can check this using the adb command:

adb shell pm list packages| findstr com.deepoon.eggchair

If the command output includes com.deepoon.eggchair, the RDC client service is present. If the output is empty, please update the system version.

To use the video playback functionality, the system needs to have DpvrVideoPlayer pre-installed. You can check this using the adb command:

adb shell pm list packages| findstr com.dpvr.videoplayer

To use the auto-start feature, the system needs to have DpvrDaemonService pre-installed. You can check this using the adb command:

adb shell pm list packages| findstr com.dpvr.daemonservice
