Enabling, disabling and callback registration¶

Initializing the Server¶

DpvrRDCServer mServer = new DpvrRDCServer();

Starting the Server¶

public void Start(string localIp = null,int port = 10086, int maxClient = 64)

Starts the server and allows you to set the following parameters.

string localIp: The local IP address (defaults to null, which automatically detects the IP address).

int port: The port number for connection listening (defaults to 10086).

int maxClient: The maximum allowed number of client connections (defaults to 64).

Stopping the Server¶

public void Stop()

Stops the server.

Client Connection State Change Callback¶

public event OnConnectState OnConnectStateChangedEvent;
public delegate void OnConnectState(DpvrRDCServer.Client client, int state);

This event is triggered when the client’s connection state changes.

Client client: parameter represents the client whose state changed.

int state: parameter indicates the connection state (1: connected, 2: disconnected).

Client Message Callback¶

public event OnMessage OnMessageEvent;
public delegate void OnMessage(DpvrRDCServer.Client client, DpvrRDCServer.ClientMessage msg);

This event handles application-specific messages received from clients.

Client client: parameter represents the client.

ClientMessage msg:parameter contains the client’s transmitted message.

The ClientMessage struct includes,

public class ClientMessage
{
    public string fromPackage;
    public string content;
}

string fromPackage: The package name from which the message was sent.

string content: The content of the transmitted message.

Example Usage¶

public static void InitServer()
{
    var mServer = new DpvrRDCServer();
    mServer.Start();
    mServer.OnMessageEvent += HandleMessageFromClient;
    mServer.OnConnectStateChangedEvent += HandleConnectState;
}

private static void HandleMessageFromClient(DpvrRDCServer.Client client, DpvrRDCServer.ClientMessage msg)
{
    Log.D($"Got message from {client.IP}: {msg.fromPackage} - {msg.content}");
}

public static void HandleConnectState(DpvrRDCServer.Client client, int state)
{
    Log.D($"Connected state changed :{client} state: {state}");
}
