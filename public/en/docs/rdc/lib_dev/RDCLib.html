Based on RDC Library for Server-side Development¶

We provide a .Net 7.0 Win64 C# library .Net7.0 Win64 C#library based on the RDC communication protocol, encapsulated for faster RDC feature development.

If your system does not have .Net 7.0,you can download LibDpvrRDC with .Net7.0 Runtime.

Reference the interface usage in the Demo.

Requires using Namespace DPVR and interface class name DpvrRDCServer.
