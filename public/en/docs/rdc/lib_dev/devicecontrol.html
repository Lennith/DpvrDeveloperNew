Device Management¶

Input State Data Structure:¶

public class InputState
{
    public bool HomeKeyBlock = false;
    public bool PowerKeyBlock = false;
    public bool TouchPadBlock = false;
    public bool VolumeKeyBlock = false;
    public bool BackKeyBlock = false;
}

bool HomeKeyBlock: Indicates whether the Home key (including the controller’s Home key short press) is blocked.

bool PowerKeyBlock: Indicates whether the Power key short press is blocked. Long press for 10 seconds to shut down cannot be blocked by this setting.

bool TouchPadBlock: Indicates whether the device’s touchpad is blocked.

bool VolumeKeyBlock: Indicates whether the volume keys are blocked.

bool BackKeyBlock: Indicates whether the Back key (including the controller’s Back key) is blocked.

Setting and Clearing Input State¶

public void DeviceSetInputState(InputState states, List<Client> clientList = null)

InputState states: Specifies the desired input state.

List<Client> clientList: Optional parameter to specify a list of clients for which the input state should be set. Default is null, meaning all clients.

Setting Volume¶

public void DeviceSetVolume(int value, List<Client> clientList = null)

int value: Volume value, range 0-100.

List<Client> clientList: Optional parameter to specify a list of clients for which the volume should be set. Default is null, meaning all clients.

Shutting Down the Device¶

public void DeviceShutdown(List<Client> clientList = null)

List<Client> clientList: Optional parameter to specify a list of clients for which the device should be shut down. Default is null, meaning all clients.

Rebooting the Device¶

public void DeviceReboot(List<Client> clientList = null)

List<Client> clientList: Optional parameter to specify a list of clients for which the device should be rebooted. Default is null, meaning all clients.

Recentering the Device¶

public void DeviceRecenter(List<Client> clientList = null)

List<Client> clientList: Optional parameter to specify a list of clients for which the device should be recentered. Default is null, meaning all clients.

Starting DPVR Cast¶

public void DeviceStartDpvrCast(List<Client> clientList = null)

Sends message 1012 to the selected clients and requests the device-side DMS to start the DPVR Cast RTSP stream.

List<Client> clientList: Optional list of clients. Default is null, meaning all clients.

Stopping DPVR Cast¶

public void DeviceStopDpvrCast(List<Client> clientList = null)

Sends message 1013 to the selected clients and requests the device-side DMS to stop the DPVR Cast RTSP stream.

List<Client> clientList: Optional list of clients. Default is null, meaning all clients.

Whether Cast is actually available must be determined from the client’s subsequent heartbeat CastRtspUrl value. An empty string means that no Cast address is currently available.
