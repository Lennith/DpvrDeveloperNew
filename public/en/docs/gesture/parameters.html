GestureSdk Parameters and Notes (Updated)

1. Purpose

This document summarizes the current runtime parameters and practical integration notes under Assets/GestureSdk.

2. Core Scripts

  • Assets/GestureSdk/Scripts/CameraManager.cs
  • Assets/GestureSdk/Scenes/GestureTest.cs

3. CameraManager Parameters

3.1 Camera

  • cameraWidth / cameraHeight / cameraFps
    • Controls camera preview resolution and FPS.
    • Keep defaults first, then tune if needed.

3.2 Gesture

  • gesturePreset
    • Preset mode (DEFAULT / PERFORMANCE / ACCURACY).
  • tickFps
    • Gesture processing tick rate.
    • Recommended: 5.
  • numHands
    • Max number of tracked hands.
    • Recommended: 1.
  • modelComplexity
    • Gesture model complexity level.
  • inputRotation
    • Input rotation, recommended: CCW_90.
  • inputScaleMode
    • Input scale mode, recommended: LETTERBOX.
  • stabilityFrames
    • Number of stable frames before committing result.
  • hysteresisEnterScale / hysteresisExitScale
    • Hysteresis thresholds for stable switching.
  • fenceMode
    • Sync strategy, recommended: AUTO.
  • fenceShortWaitMs
    • Short wait in ms, recommended: 0.
  • classificationMode
    • Classification mode (default BUILTIN).
  • emitLandmarks / includeLandmarkInJson
    • Landmark emission and JSON payload options.

3.3 Diagnostics

  • enableDiagnosticLogging
    • Enables verbose runtime logs for debugging.

4. GestureTest Parameters

  • cameraManager
    • Reference to CameraManager.
  • sphereObject
    • Sphere object for visual interaction.
  • cameraImageRect
    • RectTransform of preview image used for coordinate mapping.
  • sceneCamera
    • Scene camera reference (Camera.main fallback).
  • scaleStepFactor
    • Scale delta per gesture trigger.
  • maxScaleSteps
    • Max scale step count.
  • zDistanceFromCameraImage
    • Sphere depth offset from the CameraImage plane, computed in camera space.
  • gestureCooldownSeconds
    • Cooldown per gesture type.

5. Current Demo Gesture Behavior

  • V_SIGN
    • Activates sphere.
    • Updates sphere position once using gesture ROI center.
  • OPEN_PALM
    • Scales sphere up one step.
  • FIST
    • Scales sphere down one step.
  • THUMBS_UP
    • Randomizes sphere color.

6. Coordinate and Depth Rules

Current position mapping in GestureTest:

  1. ROI center:
    • centerX = (left + right) / 2
    • centerY = (top + bottom) / 2
  2. Horizontal compensation:
    • mappedX = 1 - centerX
  3. Vertical mapping:
    • mappedY = centerY
  4. Convert mappedX/mappedY to local coordinates on cameraImageRect, then to world coordinates.
  5. Depth handling:
    • Convert the world point on CameraImage into camera space.
    • Move toward camera by zDistanceFromCameraImage.
    • Convert back to world space.

This keeps screen alignment stable while preserving expected depth behavior.

7. Recommended Stable Defaults

  • tickFps = 5
  • numHands = 1
  • inputRotation = CCW_90
  • inputScaleMode = LETTERBOX
  • fenceMode = AUTO
  • fenceShortWaitMs = 0

8. Practical Notes

8.1 Preview works but no gesture callbacks

Check:

  • Required AARs exist under Assets/Plugins/Android.
  • CameraManager is initialized and preview started.
  • Gesture callback logs show continuous sequence updates.

8.2 Hand appears on right, sphere appears on left

Check:

  • mappedX = 1 - centerX is still present in GestureTest.
  • cameraImageRect points to the actual preview object in scene.

8.3 Vertical direction mismatch

Check:

  • Current mappedY rule in GestureTest.
  • Preview shader flip setup if it was changed.

8.4 Depth feels wrong

Check:

  • sceneCamera points to the rendering camera.
  • zDistanceFromCameraImage is tuned for the scene scale.
The sources describe zDistanceFromCameraImage depth and calculation differently. Their original descriptions are retained; no algorithm is silently changed.
