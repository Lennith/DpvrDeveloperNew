Unity Player Plugin Integration Guide

Instructions and API reference for integrating and using the DPVR Player within Unity.

01

Project Settings

  • When using in Unity, you must uncheck Multithreaded Rendering in Unity's Player Settings.
02

SDK Notes

  • DPVR Unity SDK: When using SDK version 0.8.1, do not check Use SinglePass (Android).
  • OpenXR SDK: When using OpenXR SDK, Render Mode can only be set to Multi-pass; SinglePass is likewise not supported.
02

Importing the Package

  • Import the Player.unitypackage into your Unity project.
  • The ARM64 version library is included. When using IL2CPP, you can select 64-bit for building.
03

Auto Video Playback

  • Check AutoPlay. Set MediaUrl to the video address, and VOuts to the video display target (render carrier).
  • The video display target requires a material and shader. It can be displayed on a Plane or RawImage, which require different Shaders.
04

Controlling Video Playback via Script

  • Add a script and the corresponding video target. Similar to auto-play, adjust the parameters accordingly.
  • Create a new script where you can programmatically control video playback and handle the display target.
05

API Reference: Control & Progress

Use the following APIs to control video playback and monitor duration/progress:

API Method / Property Description
player.Play(videoUri, tim) Plays the video. videoUri is the video address, tim is the start time (default is 0).
OnPreparedCallback Callback triggered when the video is prepared and ready.
player.Duration Gets the total duration of the video.
player.Current Gets the current playback progress/time.
player.Pause() Pauses the video.
player.Resume() Resumes video playback.
player.Seek(tim) Adjusts video progress. If tim=0, the video restarts from the beginning.
