Practical guide

Android: complete your first GetSerialNo call

1. Prepare your project and device

Read the device serial number on a DPVR Android device that supports DeviceManagerService and see SN=... in Logcat. DMS is a system service on the device; this task does not need an RDC server or a LAN controller. Prepare a Java Android application using package com.example.dmsdemo and a device whose firmware provides DMS. A phone or emulator without that service cannot validate this task.

Confirm the service package from a Windows host:

adb shell pm list packages | findstr com.dpvr.devicemanager

Expect a package name containing com.dpvr.devicemanager. If absent, check the headset service and firmware first.

2. Import the AIDL interfaces

Download devicemanager.zip from the current Android documentation. Copy its com/dpvr/devicemanager directory and AIDL files under the app module’s src/main/aidl/, preserving the package hierarchy. After building, the project must resolve IDeviceManager, IDeviceManagerResultListener and IDeviceManagerEventListener. These define the cross-process interface; they are not a DMS service implementation to start inside your app. If AIDL is not enabled in your project, enable it in the app module’s android Gradle configuration, sync and build.

android {
    buildFeatures {
        aidl = true
    }
}

3. Declare the Activity and check NORMAL permission

GetSerialNo requires APP_PERMISSION_NORMAL. The source permission table states that NORMAL does not require authorisation, so this minimal example does not supply a DeviceManagerKey. Merge this Activity declaration into an existing manifest or use it for the standalone example. Before switching to LAUNCHER, SYSTEM or ADMIN APIs, obtain the corresponding authorisation from DPVR. DeviceManagerKey applies to an application package and version; DeviceManagerPlatformKey applies to designated channel firmware. Both belong inside application; a placeholder string is not a valid key.

<manifest xmlns:android="http://schemas.android.com/apk/res/android">
    <application android:label="DMS SN demo">
        <activity android:name="com.example.dmsdemo.MainActivity"
                  android:exported="true">
            <intent-filter>
                <action android:name="android.intent.action.MAIN" />
                <category android:name="android.intent.category.LAUNCHER" />
            </intent-filter>
        </activity>
    </application>
</manifest>

4. Bind the service, register listeners, then submit the call

Save this complete class as app/src/main/java/com/example/dmsdemo/MainActivity.java. It uses the documented service component and AIDL methods, with the business operation changed to the verified systemInfoJobs / GetSerialNo API. Obtain the interface in onServiceConnected, register both listeners, and only then submit the call. Returning from bindService does not mean the connection is ready. The API’s Params table is empty, so this task passes null for business parameters and null for callParams, without a delay or dependency. JSON parsing uses Android’s JSONObject and does not require Gson.

package com.example.dmsdemo;

import android.app.Activity;
import android.content.ComponentName;
import android.content.Context;
import android.content.Intent;
import android.content.ServiceConnection;
import android.os.Bundle;
import android.os.Handler;
import android.os.IBinder;
import android.os.Looper;
import android.os.RemoteException;
import android.util.Log;
import com.dpvr.devicemanager.IDeviceManager;
import com.dpvr.devicemanager.IDeviceManagerEventListener;
import com.dpvr.devicemanager.IDeviceManagerResultListener;
import org.json.JSONException;
import org.json.JSONObject;

public final class MainActivity extends Activity {
    private static final String TAG = "DMS-SN";
    private final Handler main = new Handler(Looper.getMainLooper());
    private IDeviceManager service;
    private boolean bound;
    private boolean closed;
    private int serialJobId = -1;

    private final IDeviceManagerResultListener resultListener =
        new IDeviceManagerResultListener.Stub() {
            @Override public void onResult(int jobId, String result) {
                // Serialise callback handling with the call/jobID assignment.
                main.post(() -> handleResult(jobId, result));
            }
        };

    private final IDeviceManagerEventListener eventListener =
        new IDeviceManagerEventListener.Stub() {
            @Override public void onEvent(String eventType, String eventInfo) {
                // GetSerialNo needs its result callback, not an event subscription.
                main.post(() -> {
                    if (!closed) Log.d(TAG, "Event: " + eventType + " " + eventInfo);
                });
            }
        };

    private final ServiceConnection connection = new ServiceConnection() {
        @Override public void onServiceConnected(ComponentName name, IBinder binder) {
            if (closed) return;
            service = IDeviceManager.Stub.asInterface(binder);
            try {
                service.setDeviceManagerResultListener(resultListener);
                service.setDeviceManagerEventListener(eventListener);
                readSerialNumber();
            } catch (RemoteException | JSONException e) {
                Log.e(TAG, "Register listeners or submit job failed", e);
            }
        }
        @Override public void onServiceDisconnected(ComponentName name) {
            service = null;
            serialJobId = -1;
            Log.e(TAG, "DMS disconnected; do not call until connected again");
        }
    };

    @Override public void onCreate(Bundle state) {
        super.onCreate(state);
        Intent intent = new Intent("com.dpvr.devicemanager");
        intent.setComponent(new ComponentName("com.dpvr.devicemanager",
            "com.dpvr.devicemanager.DeviceManagerService"));
        try {
            bound = bindService(intent, connection, Context.BIND_AUTO_CREATE);
            if (!bound) Log.e(TAG, "DMS bind request was not accepted");
        } catch (SecurityException e) {
            Log.e(TAG, "DMS binding denied", e);
        }
    }

    private void readSerialNumber() throws RemoteException, JSONException {
        // No business parameters or delayed/dependent call options for this task.
        String raw = service.call("systemInfoJobs", "GetSerialNo", null, null);
        JSONObject callResult = new JSONObject(raw);
        int jobId = callResult.getInt("jobID");
        if (jobId < 0) {
            Log.e(TAG, "Call rejected: " + callResult.optString("errorDescription"));
            return;
        }
        serialJobId = jobId;
        Log.i(TAG, "Call accepted; awaiting result for jobID=" + jobId);
    }

    private void handleResult(int jobId, String raw) {
        if (closed || jobId != serialJobId) return;
        serialJobId = -1;
        try {
            JSONObject finished = new JSONObject(raw);
            int code = finished.getInt("returnCode");
            if (code != 0) {
                Log.e(TAG, "Job failed: returnCode=" + code
                    + ", error=" + finished.optString("error"));
                return;
            }
            // ApiFinishedResult.result is itself a JSON-serialised string.
            JSONObject payload = new JSONObject(finished.getString("result"));
            String sn = payload.getString("sn");
            Log.i(TAG, "SN=" + sn);
        } catch (JSONException e) {
            Log.e(TAG, "Unexpected result JSON: " + raw, e);
        }
    }

    @Override public void onDestroy() {
        closed = true;
        serialJobId = -1;
        if (bound) {
            unbindService(connection);
            bound = false;
        }
        service = null;
        main.removeCallbacksAndMessages(null);
        super.onDestroy();
    }
}

5. Match the jobID and read sn

call() returns a CallResult, not the serial number. Parse the case-sensitive jobID field first. A negative value means submission failed; read errorDescription. Once accepted, wait for onResult(jobId, result) and match its ID to the saved job ID. This example posts callbacks to the main thread so that callback processing follows the job ID assignment, even for a fast response. Only returnCode == 0 in the outer JSON indicates completion success. Parse its result string as JSON again and read sn. Install and launch the app, filter Logcat by DMS-SN, and expect Call accepted followed by the actual SN returned by your device.

6. Release resources and diagnose the failing stage

Each process has one effective result listener and one event listener; setting them again replaces the previous listeners. This standalone Activity owns both listeners. In onDestroy it marks the screen closed, unbinds, clears its service reference and discards pending callbacks; subsequent callbacks are ignored. In an existing application, let a shared DMS manager own this lifecycle so one screen does not replace another module’s listeners. A submitted job may still finish in the service after this screen stops listening.

If AIDL classes do not resolve, check the directory/package hierarchy and rebuild. If binding fails, verify that the firmware provides DMS and the component name is correct. If jobID is negative, record errorDescription. If no result arrives, check listener registration order, the saved ID and whether the Activity has already been destroyed. For a nonzero returnCode, record the raw code and error. The source concept and usage pages disagree on the sign of cancellation/failure codes; this example treats only zero as success without redefining the other codes. GetSerialNo does not depend on an event callback.

Sources and example scope

This tutorial combines the current interface documentation and the connection/listener/call pattern from the Java wrapper into one minimal example, with local lifecycle and callback ordering handling. It is an adapted example, not a verbatim official sample, and has not been compiled or run on hardware. The original articles and code remain available in full.
