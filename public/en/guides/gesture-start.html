Practical guide

Run the gesture sample on a headset

Verify the camera preview and four sample responses before integrating callbacks into your scene.

Prerequisites

  • Use P1 Pro 4K Camera with Android Build Support and USB debugging enabled.
  • Disable Multithreaded Rendering and grant camera permission.
01

Import and check dependencies

Import the complete Gesture.unitypackage and check the AAR files in the current package location, Assets/Plugins/Android.

Read: Import and check dependencies →
02

Build the sample for the headset

Open Assets/GestureSdk/Scenes/SampleScene.unity, select Android and Build And Run.

Read: Build the sample for the headset →
03

Verify preview and interaction

After confirming the preview, try V_SIGN, OPEN_PALM, FIST and THUMBS_UP to check placement, scaling and color changes.

Read: Verify preview and interaction →
04

Troubleshoot before integration

For no preview, check permission, AARs and multithreaded rendering. For no gestures, check initialization and seq logs. Then bind your own preview, targets and camera.

Read: Troubleshoot before integration →
The editor cannot validate the Android camera pipeline. The sphere sample is not full 3D hand tracking. Dependency paths follow the current package inventory and rendering requirements follow its bundled guide.
