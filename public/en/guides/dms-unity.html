Practical guide

Unity: bind Device Manager and read the first serial number

This page connects service checks, import, binding, listeners, a call and result parsing in one scene component. The target outcome is a device log containing [DMS] SUCCESS sn= followed by the headset serial number.

1. Check the headset service

Prepare Unity Android Build Support, a USB data cable and a headset authorized for debugging. In a Windows command prompt, run:

adb devices
adb shell pm list packages | findstr com.dpvr.devicemanager

The first command should list the headset with status device; the second should include package:com.dpvr.devicemanager. If the package is absent, check the documented firmware requirements. Importing the Unity package does not install the headset service. The example waits for an actual connection callback before submitting a request.

2. Start with NORMAL permission

systemInfoJobs/GetSerialNo requires APP_PERMISSION_NORMAL, has no business parameters and needs no additional authorization key. Do not insert a made-up key. For later LAUNCHER, SYSTEM or ADMIN APIs, obtain authorization from DPVR and configure the manifest application element: DeviceManagerKey binds the package and app version; DeviceManagerPlatformKey binds the package and firmware channel.

3. Import the package and create a test scene

  1. Download the current DpvrDeviceManager2.0.unitypackage and import it fully through Assets → Import Package → Custom Package.
  2. Check for Assets/DpvrDeviceManager/DeviceManagerClientJar.aar and Assets/DpvrDeviceManager/LitJson. This example uses the bundled LitJson, so no extra JSON library is required. Avoid duplicate types if the project already contains it. Ensure the AAR import settings include Android.
  3. Create DmsSerialNumberExample.cs in your Scripts folder and paste the complete code below. Keep the filename and class name identical.
  4. Create an empty object in a test scene and attach one instance. Temporarily avoid other components that register DMS listeners: each application has only one effective result and event listener set.

4. Complete component: connect, submit, match the result

Two AndroidJavaProxy implementations receive results and events. A third uses the connection callback verified in the current AAR. All callbacks enter a queue processed by Update on the Unity main thread, so even an early result is parsed after the submission returns and stores jobID. The 10-second diagnostic is not an API timeout or cancellation rule.

using System;
using System.Collections.Generic;
using LitJson;
using UnityEngine;
using UnityEngine.Scripting;

public sealed class DmsSerialNumberExample : MonoBehaviour
{
    private const string BridgeClass =
        "com.dpvr.devicemanagerclientjar.DeviceManagerBindMan";
    private readonly Queue<Action> mainThread = new Queue<Action>();
    private readonly object queueLock = new object();
    private AndroidJavaObject bridge;
    private ResultProxy resultProxy;
    private EventProxy eventProxy;
    private StateProxy stateProxy;
    private volatile bool closing;
    private bool bindRequested;
    private bool connected;
    private int? pendingJob;
    private float pendingSince;

    [Preserve]
    public sealed class Accepted
    {
        public int jobID;
        public string errorDescription;
    }

    [Preserve]
    public sealed class Completed
    {
        public int jobId;
        public int returnCode;
        public string result;
        public string error;
    }

    [Preserve]
    public sealed class SerialNumberResult
    {
        public string sn;
    }

    private void Start()
    {
#if UNITY_ANDROID && !UNITY_EDITOR
        try
        {
            using (var player = new AndroidJavaClass("com.unity3d.player.UnityPlayer"))
            using (var activity = player.GetStatic<AndroidJavaObject>("currentActivity"))
                bridge = new AndroidJavaObject(BridgeClass, activity);

            resultProxy = new ResultProxy((id, json) =>
                Post(() => HandleResult(id, json)));
            eventProxy = new EventProxy((type, json) =>
                Post(() => Debug.Log("[DMS] Event " + type + ": " + json)));
            stateProxy = new StateProxy(state => Post(() => HandleState(state)));

            bridge.Call("SetDeviceManagerResultListener", resultProxy);
            bridge.Call("SetDeviceManagerEventListener", eventProxy);
            bridge.Call("SetServiceStateListener", stateProxy);
            bridge.Call("SetBind");
            bindRequested = true;
            Debug.Log("[DMS] Binding requested; waiting for service connection.");
        }
        catch (Exception e)
        {
            Debug.LogError("[DMS] Setup failed: " + e);
        }
#else
        Debug.LogWarning("[DMS] Build and run on an Android headset; Editor is not supported.");
#endif
    }

    private void Post(Action action)
    {
        lock (queueLock)
        {
            if (!closing) mainThread.Enqueue(action);
        }
    }

    private void Update()
    {
        while (true)
        {
            Action action;
            lock (queueLock)
            {
                if (mainThread.Count == 0) break;
                action = mainThread.Dequeue();
            }
            try { action(); }
            catch (Exception e) { Debug.LogError("[DMS] Callback failed: " + e); }
        }
        if (pendingJob.HasValue && Time.realtimeSinceStartup - pendingSince > 10f)
        {
            Debug.LogWarning("[DMS] Still waiting for job " + pendingJob.Value +
                ". Check listeners and device logs; this is not a cancellation.");
            pendingSince = float.PositiveInfinity;
        }
    }

    private void HandleState(bool state)
    {
        connected = state;
        Debug.Log("[DMS] Connected=" + state);
        if (state && !pendingJob.HasValue) RequestSerialNumber();
        if (!state)
        {
            pendingJob = null;
            Debug.LogWarning("[DMS] Connection lost. An accepted job may still exist on the device.");
        }
    }

    public void RequestSerialNumber()
    {
        if (!connected || bridge == null || pendingJob.HasValue) return;
        try
        {
            string json = bridge.Call<string>("CallInterface",
                "systemInfoJobs", "GetSerialNo", null, null);
            if (string.IsNullOrEmpty(json))
            {
                Debug.LogError("[DMS] Empty acceptance response; check service connection.");
                return;
            }
            Accepted accepted = JsonMapper.ToObject<Accepted>(json);
            if (accepted.jobID < 0)
            {
                Debug.LogError("[DMS] Rejected: " + accepted.errorDescription);
                return;
            }
            pendingJob = accepted.jobID;
            pendingSince = Time.realtimeSinceStartup;
            Debug.Log("[DMS] Accepted jobID=" + accepted.jobID);
        }
        catch (Exception e) { Debug.LogError("[DMS] Submission failed: " + e); }
    }

    private void HandleResult(int jobId, string json)
    {
        Debug.Log("[DMS] Result jobId=" + jobId + ": " + json);
        if (!pendingJob.HasValue || jobId != pendingJob.Value) return;
        try
        {
            Completed completed = JsonMapper.ToObject<Completed>(json);
            if (completed.returnCode != 0)
            {
                Debug.LogError("[DMS] Completion failed: code=" +
                    completed.returnCode + " error=" + completed.error);
                return;
            }
            SerialNumberResult value =
                JsonMapper.ToObject<SerialNumberResult>(completed.result);
            if (value == null || string.IsNullOrEmpty(value.sn))
                Debug.LogError("[DMS] Completed without a serial number: " + json);
            else
                Debug.Log("[DMS] SUCCESS sn=" + value.sn);
        }
        finally { pendingJob = null; }
    }

    private void OnDestroy()
    {
        closing = true;
        lock (queueLock) mainThread.Clear();
        if (bridge == null) return;
        try { if (bindRequested) bridge.Call("UnBind"); }
        catch (Exception e) { Debug.LogWarning("[DMS] Unbind: " + e.Message); }
        finally { bridge.Dispose(); bridge = null; }
    }

    [Preserve]
    private sealed class ResultProxy : AndroidJavaProxy
    {
        private readonly Action<int, string> handler;
        public ResultProxy(Action<int, string> handler)
            : base(BridgeClass + "$OnDeviceManagerResult") { this.handler = handler; }
        [Preserve]
        public void OnDeviceManager(int jobId, string json) { handler(jobId, json); }
    }

    [Preserve]
    private sealed class EventProxy : AndroidJavaProxy
    {
        private readonly Action<string, string> handler;
        public EventProxy(Action<string, string> handler)
            : base(BridgeClass + "$OnDeviceManagerEventResult") { this.handler = handler; }
        [Preserve]
        public void OnDeviceManagerEvent(string type, string json) { handler(type, json); }
    }

    [Preserve]
    private sealed class StateProxy : AndroidJavaProxy
    {
        private readonly Action<bool> handler;
        public StateProxy(Action<bool> handler)
            : base(BridgeClass + "$ServiceConnectState") { this.handler = handler; }
        [Preserve]
        public void onStateChange(bool connected) { handler(connected); }
    }
}

5. Build for Android and inspect three stages

  1. Add the test scene to the build list, select Android, use project settings appropriate for the headset, and Build And Run. This example cannot call the Android service from the Unity Editor.
  2. Observe device logs from the PC:
adb logcat -s Unity

Expect Connected=True, then Accepted jobID=..., then SUCCESS sn=... after the matching job completes. Only the final line confirms business completion. A jobID means acceptance. The outer result field contains another JSON string, parsed separately to obtain sn.

6. Diagnose the stage that stopped

  • LitJson cannot be found during compilation: check the complete import and any custom assembly-definition references. Do not omit the bundled source when using a normal Scripts folder.
  • Java bridge class not found: check Android AAR import settings, the build output and that execution is on a headset.
  • No Connected=True: inspect the system service and binding logs. A fixed delay is not evidence of connection.
  • Rejected: read errorDescription. This is a NORMAL call; verify the API, device service and request before adding higher-permission keys.
  • Accepted without a result: check for overwritten listeners, destroyed scene objects and matching jobIDs. The 10-second message does not cancel the job.
  • Completion failed: retain returnCode and error. Sources differ on nonzero code meanings, so this example recognizes only 0 as success.
  • Disconnection or scene exit: the component releases its local binding; it does not promise to cancel jobs already accepted by the device. This is a single-read example, not a concurrent job framework.

Interface names, the result/event proxies, CallInterface parameters and JSON fields come from the current Unity usage guide. The business call is replaced with GetSerialNo, whose permission is explicit. The actual current package contains LitJson and DeviceManagerClientJar.aar. Static inspection of its classes.jar confirms SetServiceStateListener, ServiceConnectState.onStateChange(boolean), UnBind, and true/false notifications on connection/disconnection. The connection callback was not guessed from an incomplete web fragment.

This complete component supplies currentActivity, all fields, proxies and JSON types, corrects undefined variables and spelling from the source fragments, and adds main-thread dispatch, job correlation, diagnostics and unbinding. It has undergone source and structural review, not Unity compilation, Android packaging or headset execution. Recheck bridge compatibility if the package version changes.
