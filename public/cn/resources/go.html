电脑端操作工具

AIO GO 设备维护工具

通过电脑查看一体机信息，安装应用并执行设备维护操作。

适用设备：P2 · P1 Ultra 4K · P1 Pro 4K · P1 Pro · P1

AIO GO 与 AIO GO 2 的支持型号不同，不能仅按名称数字替换；恢复出厂等操作需先了解其影响。

适合谁
设备维护与内容部署人员
运行在哪里
Windows 安装式 GUI + USB 连接头显
开始使用 →下载Windows安装包 ↗

开始前确认

  • 准备 Windows 10 电脑、支持头显及可传数据的 USB 线；这是官方操作手册给出的环境。
  • 下载并解压官方安装包。

按步骤完成

01

安装工具

运行安装包内 Setup.exe，完成 AIO GO 安装。

阅读：安装工具 →
02

通过 USB 连接头显

开启头显并连接电脑，在工具中检查是否识别到设备。

阅读：通过 USB 连接头显 →
03

核对设备信息

先核对设备序列号和固件版本，确认当前操作对象。

阅读：核对设备信息 →
04

选择所需操作

根据任务选择应用安装、文件管理、截图、录屏或日志等功能；固件维护使用与设备匹配的文件。

阅读：选择所需操作 →

遇到问题时

  • 无法看到设备存储时，可查阅 USB 文件传输排障；它不等同于 ADB 授权排障。
  • 现有资料未覆盖所有驱动、无线连接和固件兼容条件。
  • 定制设备名称无法识别时，按官方 PDF 的 Device.config 说明处理。
