视频加密与授权

在电脑上把 MP4 制作为带设备 SN 和有效期授权的播放文件。

适用设备：P1 Max · P2 · P1 Ultra 4K · P1 Pro 4K · P1 Pro

加密方案 V3 与 GUI 软件版本 2.0.0 是不同维度。GUI 与 CLI 的字段约束和默认值不同，勿混用；当前资料不足以承诺任意平台的 SN 验证行为。

开始使用 →下载加密工具 ↗

开始前确认

  • 准备 MP4、目标头显 SN、授权截止日期和足够磁盘空间。
  • GUI 使用 Windows 10/11 x64；妥善保存本地密钥、管理员密码和管理数据。

按步骤完成

01

选择图形界面或批处理

日常内容与设备清单管理使用 GUI；配置驱动的自动化流程使用 CLI。

阅读：选择图形界面或批处理 →
02

完成密钥和设备准备

GUI 首次设置密钥与管理员密码，再录入或导入 SN；CLI 按对应手册填写 sn.txt 和 config.ini。

阅读：完成密钥和设备准备 →
03

设置期限并加密

GUI 选择 MP4、有效日期和授权设备后加密；CLI 将 MP4 放入 input_video，运行 encrypt.bat。

阅读：设置期限并加密 →
04

交付完整文件组

从输出目录取得同名 .mp4、.dpve1、.dpvei，放到目标头显内部存储同一目录，使用支持的播放器验证。

阅读：交付完整文件组 →
05

按需更新授权

CLI 的授权更新流程使用原 vei_key 更新 .dpvei，再覆盖设备旧授权；GUI 的保存并加密会重新加密并覆盖产物。

阅读：按需更新授权 →

遇到问题时

  • 失败先检查 MP4 封装、磁盘空间、同名输出和所选 SN。
  • 授权更新需要原 VEI_KEY；GUI 密钥保存后不可修改或恢复。
