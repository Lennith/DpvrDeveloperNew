RDC 远程设备控制

开发一个控制端，在局域网内管理多台头显，并与头显应用交换消息。

适用设备：P1 Max · P2 · P1 Ultra 4K · P1 Pro 4K · P1 Pro

RDC 发送内容清单，不代理文件；下载需要独立 HTTP 服务。库默认连接数不是性能保证。

开始使用 →下载远程控制开发包 ↗
你的控制端⟷ TCP / LAN ⟷多台DPVR头显

开始前确认

  • 确认设备具备 RDC 服务，按功能检查播放器等附加服务。
  • 准备局域网；自动发现还要求同一广播域并允许广播。

按步骤完成

01

选择控制端路线

Windows 64 位 .NET 7 项目可使用封装库；其他平台或需要直接接协议时阅读 TCP 消息协议。

阅读：选择控制端路线 →
02

核对设备端服务

检查 RDC、播放器及所需开机自启服务；缺少服务不能靠安装电脑端库解决。

阅读：核对设备端服务 →
03

设置连接地址

在设备端设置服务器 IP 和端口，或使用自动发现。开启自动发现后手填地址失效。

阅读：设置连接地址 →
04

启动服务端并识别设备

注册连接及消息回调，启动监听，等待设备连接并上报 SN 后再选择控制对象。

阅读：启动服务端并识别设备 →
05

验证目标功能

先核对单设备控制结果，再扩展多设备。分发内容时另外提供设备可访问的 HTTP/HTTPS 文件地址。

阅读：验证目标功能 →

遇到问题时

  • 发现失败时检查广播域、路由器广播设置和设备配置。
  • 控制命令发送成功不代表播放、投屏或下载已经完成，需读取对应状态。
