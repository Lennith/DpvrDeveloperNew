Unity 视频播放插件

在自己的 Unity 应用中显示视频，并接入播放、暂停和进度控制。

适用设备：P1 Max · P2 · P1 Ultra 4K · P1 Pro 4K · P1 Pro

这是自有应用内播放器，不是系统播放器配置或投屏接收应用；当前未执行 Unity 或头显实测。

开始使用 →下载Unity播放器插件 ↗

开始前确认

  • 关闭 Multithreaded Rendering。
  • DPVR Unity SDK 0.8.1 不启用 Use SinglePass；OpenXR 使用 Multi-pass。
  • 按指南检查 IL2CPP 与 64 位架构设置。

按步骤完成

01

导入当前插件包

解压 PlayerPlugin.zip，导入当前实际文件 Player20260904.unitypackage。

阅读：导入当前插件包 →
02

先跑通自动播放

使用自动播放示例，勾选 AutoPlay，设置 MediaUrl，并把显示载体赋给 VOuts。

阅读：先跑通自动播放 →
03

匹配显示载体与材质

Plane 使用 DPVR/PlainTextureYUV；RawImage 使用 DPVR/YUVTexture，按载体绑定对应材质。

阅读：匹配显示载体与材质 →
04

需要交互时改用脚本控制

关闭自动播放，引用 IjkPlayer、媒体地址与载体；设置 VOuts 后调用 Play，并处理准备完成回调。

阅读：需要交互时改用脚本控制 →
05

接入播放状态

使用 Duration、Current 显示状态，用 Pause、Resume、Seek 控制。时间单位未在简短指南中明确。

阅读：接入播放状态 →

遇到问题时

  • 无画面先检查渲染模式、载体、材质和媒体地址。
  • 解密播放虽在资源页列为能力，但指南不足以提供完整 V3 密钥与 URI 接入示例。
