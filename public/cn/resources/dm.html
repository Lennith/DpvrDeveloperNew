设备内开发接口

Device Manager V2 设备管理开发包

在头显应用中调用网络、应用、文件、电源与系统播放器等设备能力。

适用设备：P1 Max · P2 · P1 Ultra 4K · P1 Pro 4K · P1 Pro

这是设备内服务接口，不是远程控制台；具体固件和接口权限决定可用能力。

选择Android或Unity →下载设备管理SDK ↗

选择开发平台

Android

AIDL服务绑定与异步调用

Unity

导入插件，通过Java bridge调用

开始前确认

  • 准备支持设备及其 DeviceManagerService。
  • 先确定 Android 原生或 Unity 接入方式；按目标接口核对权限。

遇到问题时

  • 没有结果时先检查服务绑定、权限和监听器是否被覆盖。
  • 按具体 API 的版本、参数、结果和事件说明排查，不能只看资源页型号。
