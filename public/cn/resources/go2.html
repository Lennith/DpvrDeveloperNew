AIO GO 2 设备操作工具

免安装的 Windows 工具，用于画面镜像、录屏、文件传输和应用安装。

适用设备：P1 Max · P2

文件名 update.zip 在工具中有固件更新含义，不应当普通内容随意上传；固件适配需另行核对。

适合谁
设备操作与演示人员
运行在哪里
Windows 便携工具；内含 ADB / Scrcpy，首次连接使用 USB
开始使用 →下载Windows便携工具 ↗

开始前确认

  • 使用 P1 Max 或 P2，准备 Windows 电脑和 USB 数据连接。
  • 工具已集成 ADB 与 Scrcpy；不要把额外安装它们当作已证实的必需步骤。

按步骤完成

01

解压并运行

下载官方压缩包，解压后双击运行，无需安装。

阅读：解压并运行 →
02

连接并识别设备

开启头显并通过 USB 连接，等待工具读取型号、电量、SN 和系统信息。

阅读：连接并识别设备 →
03

查看或记录画面

按任务选择画面镜像、录屏、截图或日志采集。现有资料未说明全部输出位置。

阅读：查看或记录画面 →
04

传输文件或安装应用

使用文件区域传输内容；APK 区域会在传输后安装应用，先确认所选文件。

阅读：传输文件或安装应用 →

遇到问题时

  • 未识别设备时先确认头显开机和 USB 数据连接。
  • 无线开关在原界面可见，但现有资料不足以提供完整无线配对教程。
