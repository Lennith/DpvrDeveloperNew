Unity 手势识别插件

在支持相机的一体机上接入预览与手势回调，再映射到自己的场景交互。

适用设备：P1 Pro 4K Camera

示例是手势分类与球体交互，不代表完整三维手骨骼追踪；关闭多线程渲染来自当前插件内入门说明。

适合谁
Unity 交互开发者
运行在哪里
P1 Pro 4K Camera 真机内的 Unity 场景、相机与 AAR
开始使用 →下载Unity手势集成包 ↗

开始前确认

  • 仅按官网适配 P1 Pro 4K Camera，不能省略 Camera 型号限定。
  • 安装 Unity Android Build Support，切换 Android 平台，开启真机 USB 调试。
  • 授予相机权限并关闭 Multithreaded Rendering。

按步骤完成

01

导入完整插件

从 GestureDemoPlugin.zip 导入 Gesture.unitypackage。当前包 AAR 实际位于 Assets/Plugins/Android，与旧手册路径不同。

阅读：导入完整插件 →
02

在真机运行示例

打开 Assets/GestureSdk/Scenes/SampleScene.unity，连接设备并 Build And Run；编辑器不能替代 Android Camera/AAR 链路。

阅读：在真机运行示例 →
03

确认预览与四种交互

检查相机画面：V_SIGN 激活并定位球体一次，OPEN_PALM 放大，FIST 缩小，THUMBS_UP 换色。

阅读：确认预览与四种交互 →
04

接入自己的场景

让 CameraManager 引用 RawImage；让 GestureTest 引用相机管理器、目标物体、预览 RectTransform 和渲染相机。

阅读：接入自己的场景 →
05

保留稳定参数再调整

先用 tickFps=5、numHands=1、CCW_90、LETTERBOX、AUTO；位置先做 X 镜像，深度在相机空间计算。

阅读：保留稳定参数再调整 →

遇到问题时

  • 无画面：检查真机、AAR、相机权限和多线程渲染设置。
  • 有画面无手势：检查初始化、参数与连续 seq 日志。
  • 位置错位：检查预览对象、镜像补偿、渲染相机和深度值。
