设备端配置文件

系统播放器配置

用 JSON 指定自动播放的视频、画面格式、摘戴行为和播放菜单。

适用设备：P1 Max · P2 · P1 Ultra 4K · P1 Pro 4K · P1 Pro

网页和下载样例的 lockView 值不同，均为合法配置示例，不是唯一默认值；此文件不负责生成视频授权。

开始使用 →下载JSON示例 ↗

开始前确认

  • 先把视频部署到设备并确认绝对路径。
  • 确认视频的平面、全景、立体等画面格式。

按步骤完成

01

修改视频路径和格式

在 AutoPlayDisposition.json 中填写 videoPath，并按视频实际布局选择 videoModel。

阅读：修改视频路径和格式 →
02

选择播放体验

设置自动播放、常亮或摘下熄屏、重播或续播，以及是否显示菜单。lockView 控制跟随头部或固定空间。

阅读：选择播放体验 →
03

放置配置文件

在设备共享存储根目录创建 AutoVideoPlay 文件夹，将 JSON 放入其中。

阅读：放置配置文件 →
04

启动播放器核对

播放器启动时读取配置；检查路径、画面格式、摘戴和菜单是否符合所选设置。

阅读：启动播放器核对 →

遇到问题时

  • 未播放时先核对文件名、AutoVideoPlay 位置和视频绝对路径。
  • distance 仅用于平面模式 0、1、4；范围的中英原文不一致，需按设备确认。
