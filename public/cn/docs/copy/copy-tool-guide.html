拷贝工具使用指南

此工具用于批量执行任务，例如复制文件、安装 APK、解压 ZIP 以及复制 OBB/语言/OTA 包。

01

功能概览

本工具专为应用预装、批量数据复制和资源更新等场景设计。

  • 任务来源： 从外部 TF 卡或内部存储读取任务配置。
  • 支持的任务类型：
    • APK： 安装应用程序包到设备（支持目录或文件）。
    • ZIP_UNPACK： 解压 ZIP 文件到目标目录。
    • FILE： 复制任意目录或文件到目标目录。
    • OBB： 复制应用 OBB 文件到目标目录。
    • LANGUAGE_PACKAGE： 复制语言包到目标目录。
    • OTA_PACKAGE： 复制 OTA 升级包到目标目录（仅复制，不触发升级）。
  • 智能处理： 如果源文件位于 TF 卡上，APK/ZIP 文件会先复制到本地临时目录，然后再进行安装/解压。
  • UI 功能： 实时显示正在运行/已完成的任务、失败日志以及后续队列（待安装/解压任务）。支持一键清除缓存。
02

Json 配置

字段 描述
type 任务类型：APK, ZIP_UNPACK, FILE, OBB, LANGUAGE_PACKAGE, OTA_PACKAGE。
source 源路径。使用 ${EXT_SD} 代表外部 TF 卡根目录。
dist 目标路径（APK 任务自动忽略）。
name 任务名称（可选，用于 UI 显示）。

Json 示例：

[
  { "type":"APK", "source":"${EXT_SD}/AUTO_INSTALL_APPS", "name":"apps" },
  { "type":"ZIP_UNPACK", "source":"${EXT_SD}/video.zip", "dist":"/sdcard/TargetDir", "name":"videounzip" },
  { "type":"LANGUAGE_PACKAGE", "source":"${EXT_SD}/LANGUAGE", "dist":"/sdcard/Android/data", "name":"lang" },
  { "type":"FILE", "source":"${EXT_SD}/InputDir", "dist":"/sdcard/OutputDir", "name":"assets" }
]
03

快速开始

请按照以下步骤使用复制工具：

  • 1.
    安装应用： 开启设备并通过数据线连接电脑。将 CopyTool.apk 复制到设备并完成安装。
  • 2.
    准备配置： 创建名为 copy_config.json 的文件，根据所需任务进行配置，然后将其放置在 TF 卡根目录。
  • 3.
    拷贝内容： 根据copy_config.json 文件的源路径要求，把所需拷贝或安装内容放置在 TF 卡内。
  • 4.
    插入 TF 卡： 将 TF 卡插入设备内。
  • 5.
    启动应用： 打开工具；它会自动加载配置并开始执行任务。
  • 6.
    检查进度： 监控主屏幕上的进度条、成功/失败计数以及任何错误信息。
  • 7.
    清除缓存： 点击后续队列（Post Queue）区域中的“清除缓存”以删除临时文件。
