Unity Player 插件集成指南

关于在 Unity 中集成 DPVR Player 插件的说明及 API 参考。

01

项目设置

  • 在 Unity 中使用时，必须取消勾选 Player Settings 中的 Multithreaded Rendering（多线程渲染）。
02

SDK 注意事项

  • DPVR Unity SDK: 当使用 0.8.1 版本 SDK 时，不可勾选 Use SinglePass (Android)。
  • OpenXR SDK: 当使用 OpenXR SDK 时，Render Mode 只能选择 Multi-pass，同样不能使用 SinglePass。
03

导入资源包

  • 将 Player.unitypackage 导入到您的 Unity 工程中。
  • 资源包已包含 ARM64 版本库。若使用 IL2CPP 脚本后端，请在打包时选择 64 位。
03

视频自动播放

  • 勾选 AutoPlay。设置 MediaUrl 为视频地址，并将 VOuts 设置为视频显示的载体。
  • 视频显示载体需要添加材质和 Shader。支持在 Plane 或 RawImage 上显示，但二者需要添加不同的 Shader。
04

通过脚本控制播放

  • 添加脚本及对应的视频载体。其配置方式与自动播放类似，只需在参数中取消勾选自动播放并填入相关信息。
  • 您可以新建脚本，在代码中动态控制视频的播放逻辑以及显示载体的添加。
05

API 参考：控制与进度

使用以下接口控制视频播放并获取时长或进度：

API 方法 / 属性 描述说明
player.Play(videoUri, tim) 播放视频。videoUri 为地址，tim 为起播时间（默认 0）。
OnPreparedCallback 视频准备完成后的回调函数。
player.Duration 获取视频的总时长。
player.Current 获取当前的视频播放进度。
player.Pause() 暂停播放。
player.Resume() 恢复播放。
player.Seek(tim) 调整进度。若 tim=0，视频将从头开始播放。
