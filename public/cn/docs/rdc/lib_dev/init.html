开启、关闭与回调注册¶

初始化服务器¶

DpvrRDCServer mServer = new DpvrRDCServer();

开启服务器¶

public void Start(string localIp = null,int port = 10086, int maxClient = 64)

启动服务器，并设置本地IP地址，端口号，最大连接数。

string localIp： 本机IP，默认为null，自动获取ip地址。

int port： 连接监听的端口号，默认为10086。

int maxClient：允许的最大连接数，默认为64。

关闭服务器¶

public void Stop()

关闭服务器。

客户端连接状态变化回调¶

public event OnConnectState OnConnectStateChangedEvent;
public delegate void OnConnectState(DpvrRDCServer.Client client, int state);

客户端连接状态改变时触发，客户端在连接成功后，需要上传了SN信息后，才会触发该回调。

Client client：发生状态改变的客户端。

int state：连接状态，1：连接成功，2：连接断开。

客户端透传消息回调¶

public event OnMessage OnMessageEvent;
public delegate void OnMessage(DpvrRDCServer.Client client, DpvrRDCServer.ClientMessage msg);

客户端应用透传消息回调。

Client client：发生状态改变的客户端。

ClientMessage msg：客户端透传消息。

其中，ClientMessage结构体定义如下：

public class ClientMessage
{
    public string fromPackage;
    public string content;
}

string fromPackage：发送透传的应用包名。

string content：透传消息内容。

示例代码¶

public static void InitServer()
{
    var mServer = new DpvrRDCServer();
    mServer.Start();
    mServer.OnMessageEvent += HandleMessageFromClient;
    mServer.OnConnectStateChangedEvent += HandleConnectState;
}

private static void HandleMessageFromClient(DpvrRDCServer.Client client, DpvrRDCServer.ClientMessage msg)
{
    Log.D($"Got message from {client.IP}: {msg.fromPackage} - {msg.content}");
}

public static void HandleConnectState(DpvrRDCServer.Client client, int state)
{
    Log.D($"Connected state changed :{client} state: {state}");
}
