客户端管理¶

客户端数据结构¶

public class Client
{
    public string SN;
    public string IP;
    public int Port;
    public string TopPackage;
    public int BatteryLevel;
    public string CastRtspUrl;
    public int ConnectState;
}

string SN：客户端序列号。

string IP：客户端IP地址。

int Port：客户端端口号。

string TopPackage：客户端当前的最上层应用包名。

int BatteryLevel：客户端电池电量。

string CastRtspUrl：客户端当前 DPVR Cast 的 RTSP 地址；未 Cast 或地址不可用时为空字符串。该值来自客户端心跳字段 cast_rtsp_url，并不是发送 1012 后同步返回的结果。

int ConnectState：客户端连接状态，1: 已连接，2: 未连接。

获取客户端列表¶

public List<Client> ClientList;

当前已经建立过连接的客户端列表。

获取客户端实例¶

public Client GetClient(string serialNo, string ip = null)

根据客户端SN和IP获取客户端，SN的优先级高于IP，当找到符合SN的客户端对象，则不再根据IP查找。

参数：

string serialNo：需要查找的客户端SN。

string ip：需要查找的客户端IP，默认为null。

返回值：

Client：客户端对象。
