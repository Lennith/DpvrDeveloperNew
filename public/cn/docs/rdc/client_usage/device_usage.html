客户端使用¶

现有的RDC客户端服务内置了这些远端控制功能：

  1. 视频控制：包含播放视频，关闭视频，暂停\恢复播放，音量设置。

  2. 应用控制：开启应用，关闭应用。

  3. 按键屏蔽：屏蔽和解除屏蔽机身按键和触摸板。

系统要求¶

首先，确认RDC服务已经被安装在系统中，你可以通过adb指令：

adb shell pm list packages| findstr com.deepoon.eggchair

来查看是否系统中是否已经包含RDC客户端服务。如果命令行输出包含了com.deepoon.eggchair，则已经具备了RDC功能。如果返回为空，请更新系统版本。

如果需要使用视频播放功能，需要系统自带DpvrVideoPlayer，你可以通过adb指令：

adb shell pm list packages| findstr com.dpvr.videoplayer

来查看VideoPlayer预装情况。

如果需要使用开机自启功能，需要系统自带DpvrDaemonService，你可以通过adb指令：

adb shell pm list packages| findstr com.dpvr.daemonservice

来查看DpvrDaemonService的预装情况。
