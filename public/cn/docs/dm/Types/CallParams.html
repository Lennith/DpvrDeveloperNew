CallParams#

class CallParams {
    var delay = 0
    var dependencyJobId = -1
}

Property#

int delay : 调用的延迟，单位ms。。

int dependencyJobId: 依赖JobId，当指定的Job成功完成后，该Job才会被执行，否则会被取消。
