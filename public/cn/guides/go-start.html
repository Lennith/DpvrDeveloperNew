安装 AIO GO 并完成设备维护

先通过 USB 识别设备，再选择需要的功能。开机动画替换和定制型号识别是两条可选操作。

准备条件

  • 准备 Windows 10 电脑、支持型号的头显及 USB 数据线。
  • 下载并解压官方 AIO GO 安装包。只有需要更换动画时才准备图片和 ZIP 工具。
01

安装并启动

在 Windows 10 运行 DPVR AIO GO Setup.exe，完成安装后打开工具。未连接设备时显示“未找到设备”；这时先继续 USB 连接，不要直接操作维护功能。

阅读：安装并启动 →
02

通过 USB 确认识别结果

开启头显，用 USB 数据线连接电脑。等待界面显示设备型号、序列号、固件版本和 IP，再核对是否为本次要操作的设备。若仍未识别，官方界面提供驱动和连接手册入口；先排查连接，定制名称问题另见最后两步。

阅读：通过 USB 确认识别结果 →
03

按目的进入功能

按界面图标选择应用安装、文件管理、截图、录屏、日志记录或 Android 设置，并跟随该功能提示。界面还提供固件更新、恢复出厂和开机动画替换；此 PDF 未展开前两项的全部步骤，不能把它们当作连接测试。无需动画或定制型号操作时，本入门流程到此完成。

阅读：按目的进入功能 →
04

可选：准备静态或动态动画图片

静态效果：按手册制作 960×280 的 PNG 位图，手册要求 32 位 PNG，并把单图命名为 0.1.png。动态效果：准备同尺寸、同格式的 PNG 序列，按文件名顺序编号；手册建议时长 3–5 秒。选择一种效果，不需要把静态和动态流程依次执行。原文背景色表述不够清晰，不另立强制颜色规则。

阅读：可选：准备静态或动态动画图片 →
05

组织图片与动画描述

把选定图片或序列放入与 desc.txt 引用一致的两个阶段目录。下例采用原 desc 截图和 ZIP 目录截图中的 part1、part2；两目录内放置相应图片。原正文另写 part0、part1，不能把那组目录与下例混用。第一阶段循环一次，第二阶段循环；960、280 是画面尺寸，60 是手册示例的播放速率设置。

bootanimation.zip
├── part1/
├── part2/
└── desc.txt
阅读：组织图片与动画描述 →
06

保存 desc.txt 并检查空行

创建 desc.txt，按下例填写。用 ANSI 编码保存，前三行是数据，第四行必须为空。第二、三行的末项必须与实际图片文件夹名一致；完成后再次用文本编辑器打开检查。

960 280 60
p 1 0 part1
p 0 0 part2
阅读：保存 desc.txt 并检查空行 →
07

使用存储方式制作 ZIP

直接选择两个阶段目录和 desc.txt，压缩为 ZIP，方法选择“存储”，不要使用默认“标准”；ZIP 根目录不能多包一层 bootanimation 文件夹。使用 bootanimation.zip 这一名称，与压缩截图和文件选择窗口一致；正文出现的 booanimation.zip 为另一写法。压缩后检查目录与方法，原工具属性示例显示压缩率 100%。

阅读：使用存储方式制作 ZIP →
08

替换动画，或恢复原动画

确认 USB 已连接，在 AIO GO 打开“开机动画替换”，点击“开始替换”，选择并打开已检查的 ZIP，按工具提示完成。需要回到原动画时，在同一功能内点击“恢复初始化”；这里恢复的是动画，不是设备恢复出厂。静态和动态效果都使用这一入口。

阅读：替换动画，或恢复原动画 →
09

仅定制名称无法识别时：打开配置

若设备改变了型号名称，右键 AIO GO 快捷方式，选择“打开文件所在位置”。进入 Config 文件夹，用 VS Code、Notepad++ 或记事本打开 Device.config。这个操作用于名称匹配，不用于给不支持的硬件增加功能。

阅读：仅定制名称无法识别时：打开配置 →
10

在对应设备类型追加名称

找到实际设备所属类型的行，在已有名称后追加定制名称，并保留末尾竖线 |，再保存退出。官方示例：真实类型是 P1Pro、定制名称是 Windows，则该行为 P1Pro:P1Pro|Windows|。这是格式示例，不要求所有设备都添加 Windows；返回工具检查能否显示正确设备。

P1Pro:P1Pro|Windows|
