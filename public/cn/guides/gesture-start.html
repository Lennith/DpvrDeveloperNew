在真机跑通手势示例

先确认相机预览与四种示例反馈，再把回调接入自己的场景。

准备条件

  • 使用 P1 Pro 4K Camera，安装 Android 构建支持并启用 USB 调试。
  • 关闭 Multithreaded Rendering，准备授予相机权限。
01

导入并检查依赖

导入完整 Gesture.unitypackage；按当前包实际布局检查 Assets/Plugins/Android 中的 AAR。

阅读：导入并检查依赖 →
02

构建示例到真机

打开 Assets/GestureSdk/Scenes/SampleScene.unity，选择 Android 并 Build And Run。

阅读：构建示例到真机 →
03

验证预览和交互

确认预览后依次试 V_SIGN、OPEN_PALM、FIST、THUMBS_UP，观察定位、缩放和变色。

阅读：验证预览和交互 →
04

按症状排障后再集成

无画面先查相机权限、AAR 和多线程设置；有画面无手势查初始化与 seq 日志。跑通后再绑定自己的预览、目标对象与相机。

阅读：按症状排障后再集成 →

示例动作与预期结果

以下为官方Sample行为，须在P1 Pro 4K Camera真机确认。标识符以具体回调/API为准；文档同时使用V_SIGN和Vsign。

实体手势标识符预期结果
V字手势V_SIGN / Vsign激活球体，并按此次手势位置定位一次；不是连续跟随
张开手掌OPEN_PALM放大球体
握拳FIST缩小球体
竖起拇指THUMBS_UP改变球体颜色
编辑器不能验证 Android 相机链路；球体示例不等于完整三维手部追踪。依赖路径按当前包清单，新增多线程要求按插件内当前手册。
