让系统播放器启动时播放指定视频

先在一台设备上验证普通视频的自动播放，再按需要增加授权或批量分发。这里使用系统播放器，不需要编写Unity应用。配置由系统播放器启动时读取；它不会让头显开机后自动启动播放器。

1. 准备视频和设备

官网列明适用P1 Max、P2、P1 Ultra 4K、P1 Pro 4K、P1 Pro。先准备能由设备播放器正常播放的视频，并确认它的画面格式。以下示例用360°单目视频；普通平面2D视频应把videoModel改为0。

用USB数据线连接电脑，把视频放在设备共享存储根目录，命名为demo.mp4，其设备绝对路径为/sdcard/demo.mp4。先在设备上手动打开它，确认画面与声音正常。电脑看不到磁盘时，查阅P1 Max的Windows MTP排障；这不是ADB连接教程。

2. 建立完整配置文件

新建UTF-8文本文件AutoPlayDisposition.json，粘贴以下完整JSON。确认文件扩展名不是.json.txt。

{
  "isAutoPlay": 1,
  "videoPath": "/sdcard/demo.mp4",
  "videoModel": 16,
  "isSteadyOn": 0,
  "sleepTimes": 10,
  "lockView": false,
  "distance": 0,
  "isStartBeginning": 1,
  "showUI": 0
}

这个示例表示：自动播放demo.mp4；采用360°单目模式；摘下时熄屏；总是从头播放；隐藏菜单。lockView=false让画面固定在空间中。它是线上指南的示例选择，不是所有设备的默认值。

你的目标修改哪一项
换视频videoPath填写实际存在的设备绝对路径
普通平面2D视频videoModel: 0
保留播放菜单便于调试showUI: 1
从上次位置续播isStartBeginning: 0
佩戴者摘下仍保持常亮isSteadyOn: 1
一个尚未核实的字段范围：distance仅对平面模式0、1、4生效。中文文档写-120～200，英文写120～200，两份示例为0，准确范围待设备或实现确认；本例模式16不使用该字段。官网下载示例的lockView=true与本例不同，两者都是合法配置选择。

3. 放到播放器读取的位置

在共享存储根目录建立AutoVideoPlay文件夹，把JSON放进去。视频仍放在前面设置的路径，不要把电脑盘符路径写入JSON。

/sdcard/
├── demo.mp4
└── AutoVideoPlay/
    └── AutoPlayDisposition.json

退出并重新启动系统播放器。官方说明是“播放器启动时读取配置”，没有承诺编辑文件后立即热更新。

4. 在这一台头显确认最小成功结果

  1. 重新启动播放器后，确认它自动打开指定视频。
  2. 检查画面模式是否符合源视频；图像不对时先核对videoModel，不要先修改授权或SDK。
  3. 检查菜单显示、摘戴熄屏和从头播放是否符合需求；需要排查时先把showUI设为1，再重新启动播放器。
  4. 若没有播放，按顺序检查文件名、JSON语法、文件夹位置、videoPath和视频能否手动播放。把当前配置保留下来再改下一项。

5. 需要时再增加授权或批量分发

限制播放设备或有效期：使用视频加密工具生成同名.mp4、.dpve1、.dpvei三件套，同目录部署并使用支持解密的DPVR播放器验证。普通视频不要求先加密。GUI编辑授权会重新加密；CLI有仅更新授权文件的流程。

离线部署到多台设备：可用TF卡部署工具的FILE或ZIP_UNPACK任务，把视频与配置送到上述位置；复制完成不代表播放已通过验证，仍需检查目标头显。TF工具的OTA_PACKAGE只复制升级包，不触发升级。

6. 用 TF 卡把配置与视频一起部署

TF工具不支持P1 Max。对于官网列明支持的设备，先按完整安装与操作说明安装 CopyTool.apk。TF卡根目录保存 copy_config.json，InputDir 内保存刚才已经验证的 demo.mp4 和 AutoVideoPlay 文件夹。

TF card/
├── copy_config.json
└── InputDir/
    ├── demo.mp4
    └── AutoVideoPlay/
        └── AutoPlayDisposition.json
[
  { "type": "FILE", "source": "${EXT_SD}/InputDir", "dist": "/sdcard", "name": "playback-files" }
]

这是依据官方 FILE 任务格式整理的部署示例，不是工具默认配置。插卡并运行工具，查看任务结果与失败日志，再检查 /sdcard/demo.mp4 和 /sdcard/AutoVideoPlay/AutoPlayDisposition.json 是否存在。最后重新启动系统播放器，重做第4步验证；文件复制成功不能代替播放验证。
